## 一句话总结

PhaseBetweener 用**学习到的运动相位调节混合专家网络**，让角色在前往目标关键帧时持续产生步态和身体细节；再把“以当前身体为参照”和“以目标姿态为参照”的两套预测融合，逐帧生成自然过渡。它解决的是**给定姿态与时间的补间**，相位在内部帮助运动推进，并不代替用户的目标或动作语义。[§3、图2][paper]

## 研究背景与动机

**领域现状：** 动画师可以用少量关键姿态描述一段表演，再让系统补出中间帧。神经补间已经能处理短时过渡；相位控制网络也已用于交互角色，但通常采用固定控制窗口。[§1–2][paper]

**现有痛点：** 两个关键帧相隔越久，单纯姿态插值越容易把走路变成滑向终点；神经模型也可能平均掉抬腿、摆臂和爬行细节。起终点处于不同步态阶段，或目标距离超出训练分布时，这种问题更加明显。[§1、§5.1、§5.3][paper]

**核心矛盾：** “离终点还剩一秒”无法说明身体此刻该抬左脚还是落右脚。同样的目标姿态与剩余时间对应许多中间动作，只凭倒计时回归下一帧，容易混合本应属于不同运动阶段的姿态；持续向前生成又会积累误差，妨碍最终对齐。

**本文目标：** 在稀疏关键帧、可变过渡时间和人工编辑目标下，保持动作的动态细节，提高长时间补间与目标接近精度，并提供动画制作工具。[§1、§5][paper]

**切入角度：** 用周期自编码器从关节速度中提取内部运动阶段，让网络知道“运动走到了哪里”；同时在目标坐标系中预测身体，以减轻仅在当前坐标系逐帧推进产生的漂移。[§3.1–3.2][paper]

**核心 idea：** 先离线学习相位，再用相位窗口生成专家混合权重；动作网络根据当前身体、目标姿态、剩余时间、轨迹与接触历史预测下一帧及相位更新。两种坐标系的动作预测按时间融合，接触预测辅助脚部修正，结果反馈到下一步。[图2、图9、§4–5][paper]

## 方法详解

### 整体框架

训练时，动作捕捉数据先经过 **Periodic Autoencoder（PAE）**，得到供监督与门控使用的相位特征；随后训练门控网络和运动预测网络。运行时，用户提供起始姿态、目标关键帧和过渡时间，可再指定轨迹或已训练的风格标签。系统维护当前状态与相位窗口，每次调用生成下一帧，持续反馈，直到进入下一段关键帧过渡。[§3–4][paper]

先看中间的两路：**身体与目标条件进入运动预测网络，相位进入门控网络**；门控得到的权重用于混合专家参数。再沿输出走到双坐标融合和脚部 IK，最后看状态如何回到下一帧。最上方的 PAE 是离线特征学习环节，论文明确不要求运行时保留这张相位提取网络。这里的连续动作直接由运动预测网络产生，没有离散动作 token 解码或物理仿真器。[§4.1][paper]

### 关键设计

1. **学习相位：用内部运动阶段缓解长时间补间的歧义**

   PAE 接收以角色根节点为参照、持续2秒的所有关节3D速度，学习5个相位通道。每个通道的相位角和振幅形成二维圆周表示；论文式1可写成：

   <div class="equation">𝒫<sub>i</sub> = A<sub>i</sub> ⊙ (sin Θ<sub>i</sub>, cos Θ<sub>i</sub>)</div>

   其中 Aᵢ 表示通道振幅，Θᵢ 表示相位角，乘法按通道进行。相比只保留一个倒计时，相位可以通过频率更新持续前进，帮助网络区分周期中不同动作阶段。**通道不是预定义的左脚、右手或“跳跃”标签**；它由运动重建学习得到。接触相位与学习相位也是两套不同表示，本文的主要版本采用后者。[§3.1、§4.1、图3][paper]

2. **相位门控与混合专家：改变下一帧生成器的参数组合**

   系统取过去1秒到未来1秒的13个采样点，每个点含5通道二维相位，构成130维相位输入。门控网络预测8个专家的混合系数；运动预测网络由三层全连接网络组成，各层参数根据系数混合。可用教学简式理解：Wᵢ = ∑ₖ₌₁⁸ gᵢₖ Wₖ。这不是从8段动作中检索并拼接，也不是8种已命名技能的硬选择。[§4、§4.2；作者训练代码][network]

   另一路包含22关节的当前位置、前向／向上方向、速度，目标姿态、目标相对根轨迹及时间差，以及脚、手、髋的历史接触信息。旋转以两个3D方向表达；最终连续骨架由网络预测。未来轨迹与相位窗口是系统维护的控制／预测状态，不能理解成运行时提前取得真实未来动作。[§4.2][paper]

3. **双坐标预测：从当前身体和目标姿态两侧约束同一步输出**

   单纯累加当前根坐标系下的预测，容易在靠近目标时仍有位置或姿态偏差。因此，网络同时输出当前根坐标系和目标参照系下的根轨迹、关节状态。目标侧关节参照更细：位置以各目标关节为原点，方向采用目标根节点方向，而非仅给整个人体一个统一目标平移。[§3.2、§4.2][paper]

   将两路变换到同一参照系后，再用随剩余时间变化的权重融合。论文式2的直观形式如下，其中 λ 是时间相关权重，T 把目标参照预测变到当前参照系：

   <div class="equation">y = (1 − λ) y<sub>ego</sub> + λ T<sub>goal→ego</sub> y<sub>goal</sub></div>

   **这里的“双向”是两种空间参照，不是分别向前与倒放生成整段动画。** 论文用 smooth-step 描述时间权重；公开 Authoring 控制器的当前实现将时间权重平方，具体复现应核对代码版本。[图9][paper] · [控制器源码][controller]

4. **相位、接触和身体共同递归：生成器还要预测下一步的状态**

   输出除了下一帧身体，还包含未来7个采样点的两路根轨迹、5个接触预测以及相位／频率／振幅更新。频率推进相位，和预测相位状态融合后继续门控下一帧。这样长时间过渡并不要求一次性生成一个更长的固定长度张量。[§4.2][paper]

   接触标签在数据处理时依据高度、速度阈值构建；运行时用预测标签驱动脚部 IK，减少脚滑。**接触输出是预测信号，脚部 IK 是后处理，两者不等于全身接触或动力学约束已经严格满足。** 论文对目标姿态的误差也并非零。[§4.1、§5、表2][paper]

5. **轨迹与风格是额外控制接口，相位本身不替代语义控制**

   用户可修改关键点位置、方向及连接路径；参数 τ 调节人为期望轨迹和模型预测轨迹的融合，论文实验中 τ=0 为完全自回归轨迹，τ=1 为更强的预设路径控制。它影响下一次输入，没有给出严格路径约束求解器。[§5.4、表4][paper]

   若希望两个站姿之间先爬行再起身，需要在训练时额外加入 one-hot 行为／风格标签，例如 crawling、aiming。作者展示的这个接口依赖带标签版本；基础相位模型不会因为相位可编辑就自动理解“爬过去”的自然语言指令。[图8、§5.4][paper]

### 一个完整例子

沿用论文图8的案例：**起点和终点都是站姿，间隔60帧即2秒，中间希望角色爬行。** 以下步骤说明系统的数据流，不是本次运行结果。

1. 动画师摆好两个关键姿态，指定2秒时长；可沿蓝色路径编辑位置与朝向，并使用训练过的 crawling 控制通道。
2. 控制器将当前身体、目标姿态、剩余时间和路径变成数值特征；内部相位窗口送入门控，得到8个专家的软混合权重。
3. 运动网络预测下一帧，同时给出当前参照与目标参照下的身体／轨迹，以及接触和相位更新。专家作用于运动生成参数，不输出“现在开始爬行”的程序。
4. 控制器融合两套空间预测，结合接触信息做脚部修正，再把下一帧身体和更新相位送回网络；接近终点时提高目标参照的影响。
5. 作者展示中，带行为标签的版本产生站立→爬行→站立过渡，未加标签的版本倾向普通走路。是否精确碰到某个地面点或完整满足所有末端位置，仍需单独检查；图8没有给出此类硬保证。[图8、§5.4、§6][paper]

### 训练/推理

**数据与监督：** 使用 LaFAN1，受试者1–4用于训练，受试者5的13段序列用于测试。全文记载共处理64段、399,139帧，约3.69小时、30 fps，并做镜像增强。训练时为当前帧随机选取未来1–60帧的目标，即最长2秒；损失为各输出特征的 MSE。[§4–4.2][paper]

**两个学习阶段：** 先以2秒关节速度窗口训练 PAE、提取相位，论文报告10 epochs约3小时；再以这些固定提取的相位特征训练门控与运动网络。公开 `InBetweeningNetwork.py` 的默认值为150 epochs、batch32、dropout0.3、8专家，门控隐藏128、主网隐藏512、学习率和权重衰减均为1e−4，使用 AdamW 与余弦重启调度。这些是**当前代码设置**，不是本次训练结果；论文未给出完整流水线的总GPU小时。[§4.1][paper] · [训练代码][network]

**运行路径：** Unity 以当前关键姿态初始化角色，输入目标与时间后逐帧推理、融合、修正并反馈。作者在 Alienware x17 R2、i9-12900HK、RTX3080Ti 上报告**每角色每帧7–9 ms，含控制参数处理、推理和场景渲染**，动画运行30 Hz。该数值不是只测网络前向，也不是本次本机复测。[§5][paper]

**公开可复现范围：** 作者提供 Unity2020.3.18f1、Barracuda2.0.0／ONNX 的演示说明，数据导出、训练和导入流程，以及预训练模型与已处理动作下载。人形与四足使用不同训练模型；扩展到四足时重新训练 PAE 和运动生成器，不是同一权重跨骨架零样本迁移。[§5.6][paper] · [复现说明][manual]

### 关键发现

1. **主要优势在较长过渡，而非所有长度都最佳。** 人体120帧时，L2P为3.89，对比RTN的5.59；30帧时本文2.71反而高于RTN2.23。四足30帧的两项误差也由Transformer更低，60／90帧才由本文更低。[表3、表6][paper]
2. **相位主要保护动作推进与细节。** 120帧的角度更新由RTN27.3提高到47.6，仍低于GT63.0；这和长时补间避免停滞的目标一致，但不是恢复全部真实细节。[表3][paper]
3. **接近目标和精确约束是不同层次。** 双向控制显著降低末端误差，论文仍在§6承认目标可能不完全到位，需要额外IK逻辑处理末端偏差。[表2、§6][paper]
4. **压力测试和工作流实验说明可用性，但样本范围有限。** 作者展示10米／2秒及30米以上／10秒的过渡，后者起步仍略显僵硬；两位动画师的耗时结果也不应外推为整个动画行业统一的效率倍数。[§5.3、§5.5][paper]

## 亮点与洞察

- **把时间拆成目标倒计时和内部运动阶段：** 前者规定何时到达，后者避免途中步态停滞；二者承担不同职责，适合解释为什么一个时间embedding不总能解决长时补间。
- **相位用于调节生成器而非绑定语义：** 学习通道通过专家权重影响连续动态，行为标签另设接口。这使动作节奏表示与“做什么”的控制保持清楚的功能区分。
- **把目标参照推广到全身关节：** 相比只控制根轨迹，对各目标关节建立参照能直接改善全身姿态接近目标的表现，原表2提供了针对性验证。
- **完整制作闭环：** 关键帧、路径、姿态编辑、ONNX推理和Unity控制器一起交付，价值不仅来自离线误差，还来自动画师可以实际修改输入的工作流。[§5、作者工程][manual]

## 局限与展望

1. **训练分布仍决定可生成动作。** 相位支持时间外推，不等于自动学会训练数据之外的新技能；用户设置的距离与时间也要合理。论文将自动学习时长分布列为未来方向。[§6][paper]
2. **没有严格终点、接触或物理保证。** 双坐标融合、预测接触与脚部IK是不同层次的机制，现有表格仍有误差；对手部接触、障碍物碰撞、动力学稳定等要求，需要额外环境感知或约束处理。[§5–6][paper]
3. **相位维度不可直接当动作语言。** 5通道并无命名语义或部位独立保证；风格控制依赖额外标签训练。若接入LLM，LLM更适合输出关键姿态／时长／已支持标签，再由生成器实现，不宜假设可直接编辑某相位通道来精确命令左手。[基于§4–5的接口分析][paper]
4. **多样性与跨骨架仍有边界。** 本文不是对同一条件采样多种轨迹的扩散模型；四足实验重新训练两个网络，不能当作直接跨拓扑迁移证据。多角色互动与更丰富的多样性仍被列为后续工作。[§5.6、§6][paper]
5. **数据驱动的姿态接近尚未覆盖复杂环境交互。** 给出一个可达关键姿态与真正安全完成途中动作并非同一问题；论文建议加入环境和交互传感器。未来可以在维持相位连贯的同时，验证中途接触、避碰与局部编辑是否保留已有动作。[§6；后半句为本文延伸][paper]

## 相关工作与启发

- **[DeepPhase：Periodic Autoencoders for Learning Motion Phase Manifolds](https://github.com/sebastianstarke/AI4Animation/tree/master/AI4Animation/SIGGRAPH_2022)（SIGGRAPH 2022）：** 为本文提供离线相位表示。PhaseBetweener进一步把它用于可变目标时间的关键帧补间，另外训练相位门控和动作预测网络；不是只运行DeepPhase就能得到补间。
- **[Local Motion Phases for Learning Multi-Contact Character Movements](https://doi.org/10.1145/3386569.3392450)（SIGGRAPH 2020）：** 其接触相位是本文的对照表示；学习相位可以利用没有稳定接触的上身／肢体动态。表1说明表示差别，不能由此把两个方法的每个通道都解释成相同语义。
- **[Robust Motion In-betweening](https://github.com/ubisoft/ubisoft-laforge-animation-dataset)（SIGGRAPH 2020）：** 提供LaFAN1与RTN基线。本文重点改善长时过渡和相位不一致导致的动作平均，而不是证明所有短期误差都优于RTN。
- **[Motion In-Betweening via Two-Stage Transformers](https://doi.org/10.1145/3550454.3555454)（SIGGRAPH Asia 2022）：** 通过上下文与细节两阶段生成过渡；本文用逐帧自回归、相位门控与双坐标控制。它是四足表6的比较对象，人体表3并未列出该方法。
- **[Neural State Machine for Character-Scene Interactions](https://doi.org/10.1145/3355089.3356505)（SIGGRAPH Asia 2019）：** 本文借鉴双参照根轨迹控制，并扩展到全身关节预测；但没有继承完整环境交互能力，不能仅因引用该方法便宣称具备场景碰撞处理。
- **启发：** 将“目标是什么、何时到达”与“途中动态怎样持续推进”分开建模，再在连续动作端独立检查关键帧和接触误差，比把相位、时间与动作语义混成一个控制量更清楚。
