## 一句话总结

PersonaGest 先把身体动作编码成一层“语义内容码”和七层“风格残差码”，再让两个生成阶段分工：根据语音产生内容，根据参考动作补上个人风格。它同时生成上身、手、下身和面部，但面部采用独立的普通 VQ 分支，没有身体分支那套显式风格残差。

## 研究背景与动机

**领域现状：** 共语手势生成已经可以从语音生成连贯的身体动作，VQ-VAE/RVQ-VAE 则把连续动作压缩成较短的离散序列，方便 Transformer 预测。参考动作控制进一步允许用户指定“像这个人一样说话”。不过，动作码通常靠重建目标学习，码本本身未必知道哪些差异来自句子内容，哪些来自个人表达习惯。

**现有痛点：** 假设同一句解说由两位虚拟讲解员说出，一位常以较大幅度展开双臂，另一位手势克制。理想系统应该保留与话语相符的指示、比划或节拍，同时采用各自习惯。直接使用一个混合表示，可能把参考片段的特定动作内容一起带入新语音，也可能只学到大致动作幅度，却丢失稳定的个人特点。

**核心矛盾：** 语义和风格共同决定同一组关节运动，没有天然独立的输入通道。一个抬手既可能是在指物，也可能体现个人习惯；“重建得像”不会自动产生可以分别控制的内容变量与风格变量。残差量化虽然有层次，但第一层与后续层也不会天然分别等于语义和风格。

**本文目标：** 在训练未见的说话人上，生成与新语音相协调、同时贴近给定参考动作风格的全身共语动作，并支持上身、手部、下身分别取用不同参考来源。论文的“零样本”指测试说话人未参加训练，推理仍需要参考动作来指定目标风格。

**切入角度：** 作者把表示学习和生成一起设计：先给第一层码本加入粗粒度手势语义结构，再利用说话人对比学习与音素预测，让不同层倾向于承载不同信息。生成时也沿用这个分工，避免把内容与风格一次性混合预测。

**核心 idea：** 先确定“此时适合什么类型的手势”，再决定“以谁的习惯完成它”。前者通过语义引导的内容码与迭代掩码生成实现，后者通过参考动作的残差风格码实现；最后在解码端重新融合音频节奏并协调身体部位，让分开建模的表示重新组成一个人。

## 方法详解

### 整体框架

训练分两阶段。第一阶段学习带语义结构的动作 tokenizer：上身、双手、下身各自使用 RVQ，面部使用普通 VQ；内容表示经过多尺度音频融合 MSAF 和跨部位注意力 CPA，再与风格表示相加重建动作。第二阶段冻结第一阶段模型，训练内容掩码 Transformer（CMT）和风格残差 Transformer（SRT）。推理时，语音与说话人条件进入 CMT，参考动作经过已训练的 tokenizer 提取风格，SRT 按残差层补全风格码，最后复用融合模块与解码器输出动作。

### 关键设计

1. **语义分区的第一层码本：让内容码先落在合适的手势类型里**

   动作先被划分为上身、手、下身、面部四路，经卷积编码器将时间长度压缩为原来的四分之一。身体三路的第一层码本采用 SMoC（Semantic-Aware Motion Codebook），按“无手势、节拍、指示、象似、隐喻”五种粗粒度类别组织。音频和转录文本经语义预测器产生逐时刻语义分数，正文公式从两个被选中类别的码本并集中寻找最接近的向量。

   训练时使用带 Gumbel 噪声的选择，并根据标注的手势强度调整温度：语义强度高的位置选择更集中，弱的位置保留更多探索。量化推理去掉 Gumbel 噪声，采用最近邻选择。附录写码本大小为 512，同时写五个分区各有 102 项、共 510 个槽位；剩余两项如何处理未交代，不能自行补齐机制。这里可解释的是五类分区，分区内部的具体码仍是学习到的向量，不是每个 token 都有一句可读的动作说明。[§3.1、式 2](https://arxiv.org/html/2605.07252v1#S3.SS1)、[附录 B.1](https://arxiv.org/html/2605.07252v1#A2)。

2. **一层内容、七层风格：用不同监督推动残差层形成分工**

   身体每一路总共八层量化：第一层承载内容，后面七层编码剩余误差并作为风格表示。作者并不只给层命名，还对风格表示施加 InfoNCE：同一说话人的不同片段作为正样本，不同说话人作为负样本；对内容表示增加音素预测，使其保留与话语有关的信息。附录的音素预测头覆盖 71 个 ARPABET 类别。

   这种监督鼓励风格层聚合同一个人的习惯，内容层保留语音线索。它提供的是统计上的分离，并未证明内容层完全不含说话人身份。面部由于主要承担语音相关的口型运动，采用普通 VQ-VAE，显式设定面部风格项为零。[式 1、5–7](https://arxiv.org/html/2605.07252v1#S3.SS1)。

3. **MSAF 与 CPA：离散码之后仍需要音频和身体各部位相互协调**

   量化会丢掉连续细节，仅将不同部位分别解码，也容易产生身体动作不协调。MSAF 把原尺度、二倍池化、四倍池化的音频特征融合成注意力的键和值，再让各部位内容表示查询它们。手部变化快，因此查询来自时间差分得到的速度特征；上身、下身和面部使用包含跨部位上下文的可学习全局查询。音频信息通过带门控的残差连接加入内容表示。

   CPA 随后把同一时刻的四个部位视作四个 token，使用注意力交换信息，再拆回各分支。按照原文式 1，可简化理解为：

   <div class="equation">m̂<sup>p</sup> = D<sup>p</sup>( CPA( MSAF({z<sub>c</sub><sup>p</sup>}, a) )<sup>p</sup> + z<sub>s</sub><sup>p</sup> )</div>

   其中 p 是部位，a 是音频，z<sub>c</sub><sup>p</sup> 与 z<sub>s</sub><sup>p</sup> 分别为内容和风格表示。面部 z<sub>s</sub><sup>face</sup>=0。这意味着最终动作并非只由离散码决定，解码时仍持续使用音频。[图 2、式 1、3–4](https://arxiv.org/html/2605.07252v1#S3.F2)。

4. **语义引导的内容生成：先稳定重要位置，再反复修正不确定位置**

   CMT 采用掩码生成。语音由冻结的 Whisper-base 编码器提取特征，再与可学习的说话人 ID 嵌入作为条件输入。训练时，对语义较模糊的位置优先施加掩码，同时保留随机掩码部分；推理时，从被遮蔽的内容序列出发，多轮预测并重新遮蔽不可靠位置。

   重新遮蔽不只看模型对 token 的置信度，也看语义分数。默认语义权重 0.6、预测置信度权重 0.4，随机比例 r=0.2，共运行 18 轮，内容 CFG scale 为 4。低语义分数且低置信度的位置更优先被重做。这是按整段内容迭代修正的 Transformer，不是把动作词加入自然语言大模型，也不是逐帧因果生成。[§3.2.1、式 8–9](https://arxiv.org/html/2605.07252v1#S3.SS2)。

5. **参考风格逐层补全：沿残差层串行，时间位置并行**

   参考动作先经过训练好的 RVQ-VAE，取得七层风格 token。SRT 预测某一残差层时，把内容嵌入与此前已经生成的残差层相加作为输入，并用参考风格提供条件。训练随机抽取一个目标层；推理从第一层风格残差逐层推进到第七层，每一层内的时间位置并行生成。每个身体分支分别建模，面部只有 CMT。

   附录中的参考条件来自参考片段随机抽取的 25%–50% 帧，并通过对风格前缀的交叉注意力得到全局风格 token；风格 CFG scale 为 3。这使生成动作可以继承示例的表达习惯，而不要求逐帧复制参考动作。它也支持不同身体部位使用不同人的参考，但不提供指定帧、关节轨迹或接触点的硬约束。[§3.2.2、式 10](https://arxiv.org/html/2605.07252v1#S3.SS2)、[附录 B.1](https://arxiv.org/html/2605.07252v1#A2)。

### 一个完整例子

沿用论文[附录 G、图 10](https://arxiv.org/html/2605.07252v1#A7)的“两个参考、分部位组合风格”设置：给系统一段新解说音频，希望上身采用参考 A 的风格，双手和下身采用参考 B 的风格。以下过程是教学展开，具体中间 token 并非作者公布的运行记录。

1. **准备输入。** 输入新语音以及方法所需的说话人条件；语义预测器按论文描述结合语音和转录文本。A、B 是动作序列参考，不是单张人物照片，也不只是文本标签。论文未交代部署中如何自动取得转录文本，以及未见说话人如何映射到已学习的 ID 嵌入。
2. **生成内容。** Whisper 提取新语音特征，四路 CMT 在 18 轮迭代中生成内容码。比如某个强调位置得到较高的手势语义分数，模型会较早稳定这个位置，继续修正其他不确定位置。不能把这里的粗粒度语义分数直接解释为“右手必须准确指向屏幕第三项”。
3. **提取并组合风格。** 分别编码 A、B，保留 A 的上身风格 token，保留 B 的手和下身风格 token。这些是残差层的学习表示，既不是自然语言，也不是把 A、B 的完整动作片段直接拼起来。
4. **补全七层风格。** 三路 SRT 根据各自内容码、已生成残差与所选参考，逐层完成风格序列。面部不参与这次风格替换，沿其内容分支生成。
5. **重新协调并解码。** 四路内容表示通过 MSAF 接收新音频的节奏，通过 CPA 交换身体上下文，再与对应风格表示相加，分别解码并组成全身结果。长语音采用重叠窗口和融合处理，生成的动作不要求与两个参考逐帧对应。

作者展示了这种分部位组合的定性结果，但没有给出“换手部风格后上身逐帧完全保持”的约束评测。因此它支持的是分部位风格条件组合，不能视作已验证的局部动作编辑器。

### 训练/推理

**数据与监督。** BEAT2 含约 60 小时、25 位说话人；本文使用 20 位做训练/验证及同身份测试，另外 5 位用于未见说话人的零样本测试。动作按 30 fps 处理，训练窗口为 128 帧、步长 20 帧。作者说明所有基线使用公开实现，并在同一 20 人划分及预处理下重新训练。该划分是理解本文结果的前提，不能拿别篇论文的 BEAT2 数字直接排位。[§4.1](https://arxiv.org/html/2605.07252v1#S4.SS1)、[附录 B.2](https://arxiv.org/html/2605.07252v1#A2)。

**第一阶段。** RVQ-VAE 训练 20K 次迭代，batch size 128，学习率 2×10⁻⁴。损失包括动作重建、速度、语义多标签分类、风格对比、内容音素预测，以及量化与 commitment 项。面部的普通 VQ 分支一同参与四部位重建和融合，不强行为它增加七层风格码。

**第二阶段。** 冻结第一阶段模型，CMT 训练 20 epochs，学习率 2×10⁻⁴；SRT 训练 120 epochs，学习率 8×10⁻⁴。两者使用 8 层 Transformer、6 个注意力头、384 维隐空间、1024 维前馈层。Whisper-base 冻结。论文披露使用 NVIDIA A100，但没有给出 GPU 数量或完整训练时长，不能换算总 GPU-hours。

**长序列推理。** 每窗 128 帧，步长 96 帧，重叠 32 帧。后一窗口锁住前一窗口最后 8 个内容 token，剩余 24 个内容 token 继续生成；风格 token 每窗独立生成，没有锁定前缀。解码后的重叠区用 shifted Hann overlap-add 融合，根节点平移速度再积分并高通处理。固定的是内容码前缀，不是最终关节轨迹，也不保证风格细节原样跨窗保留。[附录 B.3](https://arxiv.org/html/2605.07252v1#A2)。

### 消融实验

**语义码本、音频融合与跨部位协调：** 原文[表 4](https://arxiv.org/html/2605.07252v1#S5.T4)移除各模块，未见说话人重建结果如下。仅列原表的 FGD 和 Diversity，比较同一张表内部的变化。

| tokenizer 设置 | FGD ↓（原表数值） | Diversity ↑ |
|---|---:|---:|
| 去掉全局查询 Qlearn | 1.142 | 5.489 |
| 去掉 MSAF 音频融合 | 1.131 | 5.445 |
| 去掉 SMoC 语义分区 | 1.193 | 4.460 |
| 去掉 CPA 跨部位注意力 | 1.059 | 5.522 |
| 完整 tokenizer | 0.956 | 6.389 |

表 4 未统一标明显示尺度，其中完整重建模型的 FGDsk 写为 5.169，而表 3 写为 0.517（表头 ×10⁻¹），存在近十倍的尺度差异。这里保留原表，不据此推导跨表提升。表 4 上半部还报告 NBC=BC重建/BC真实，作者标注 ↓；按定义更合理的参照是接近 1，不能推广成越接近 0 越好。

**语义掩码是否有用：** 同一[表 4](https://arxiv.org/html/2605.07252v1#S5.T4)的生成部分去掉 SAM 后，未见说话人的 FGD 从 2.311 升到 2.668，BC 从 0.826±0.040 降到 0.776±0.036，Diversity 从 11.970 降到 11.332。这一设置同时去掉训练掩码优先级与推理语义引导，不是只改推理一个开关。

**风格对比与内容音素监督：** [表 5](https://arxiv.org/html/2605.07252v1#S5.T5)冻结表示后训练线性说话人分类器，以下为 All 列准确率（%）。风格侧更可辨识说明它保留更多说话人信息，内容侧仍可识别身份说明分离并非绝对。

| 训练目标 | 内容 → 说话人 | 风格 → 说话人 |
|---|---:|---:|
| 去掉风格对比损失 | 9.7 | 49.5 |
| 同时去掉风格对比与音素监督 | 17.6 | 54.2 |
| 完整模型 | 12.1 | 78.9 |

**重新遮蔽参数：** [附录表 12](https://arxiv.org/html/2605.07252v1#A6.T12)中默认权重 (0.6, 0.4) 的 FGD=2.311，优于仅看置信度的 2.463 和仅看语义的 2.642；但 (0.4, 0.6) 的 LVD=4.32 优于默认 4.63。随机比例从 0.2 提高到 0.4/0.6/0.8 时，FGD 变为 2.393/2.421/2.534，同时 Diversity 上升到 12.456/12.779/12.964，体现分布接近程度与多样性的取舍，不能概括成所有指标都变差。

**语义分类补充检查：** [附录表 10](https://arxiv.org/html/2605.07252v1#A6.T10)用在真实动作上训练的五类手势分类器检查生成动作。真实动作准确率/F1 为 81.49%/80.26%，生成动作为 77.67%/77.01%。这是粗粒度手势类别的一致性检查，不是自然语言指令完成率，也不是指向位置准确率。

### 关键发现

1. **未见说话人的分布与节拍指标较好，但并非每项领先。** 表 1 的两种 FGD、BC 和 LVD 优于所列基线；GestureLSM 的 MSE 更低，EchoMask 的 Diversity 更高。tokenizer 表中，RVQ-VAE (S) 的 FGD 也优于 PersonaGest，不能把表示改进概括为所有重建指标全面提升。
2. **风格目标的收益比“完全像真人”更明确。** 参考风格任务的 FGD/FGDsk、BC 和人评风格一致性表现突出，但 ZeroEGGS 的 MSE/LVD 更低，SynTalker 的人评拟人性为 3.63，高于 PersonaGest 的 3.52。风格贴近和动作自然度仍有取舍。
3. **分离与再融合共同起作用。** 风格层对说话人的可辨识度明显提高，语义码本、音频融合、跨部位注意力和语义掩码又各自改善同表对照结果。它的成功不是“把八层残差直接命名为内容和风格”，而是表示监督、生成顺序与解码条件一起设计。

## 亮点与洞察

- **让表示的分工对应控制入口：** 内容层主要由语音和语义引导，残差层由示例风格引导，使“换风格”有了明确的数据通道，而不只依赖一个混合条件向量。
- **语义先验进入了 tokenizer 与采样两处：** SMoC 约束表示的组织方式，SAM 再约束生成过程的修正优先级。这比仅在最终生成器输入中追加文本特征更深入。
- **承认分部位建模还需要重新协调：** 独立生成有利于风格组合，CPA 则负责交换跨部位上下文；MSAF 让压缩后的表示重新得到音频细节，是分而治之之后必要的合流。
- **给出未见身份与线性探针证据：** 测试不仅看整体 FGD，也检查从表示能否读出说话人身份。但内容残留身份信息的结果同样应保留，它为更严格的解耦评测提供了问题。

## 局限与展望

1. **语义范围有限。** 五类手势和音素监督不能表达“右手指向屏幕左上角、维持两秒”这类精确目标。论文没有外部空间目标、物体接触、视线目标或源动作保真编辑的约束评测。
2. **风格来自参考动作与说话人标签。** 没有参考片段时如何可靠指定新风格，仍是作者列出的未来方向；把文字情绪描述变成风格也未在本文完成。InfoNCE 以说话人身份为代理，不能证明已把情绪、内容、个人习惯完全拆开。
3. **面部没有同等级的个性化控制。** 面部分支没有显式内容/风格拆分，不能由身体风格组合结果推导出面部表情风格也可同样迁移。
4. **窗口生成不等于实时交互。** 128 帧窗口约为 4.27 秒，内容迭代生成后才解码。长序列锁定内容前缀并做融合，有助于连续，但风格逐窗独立，不能保证逐帧不跳变，更不能将 s/s 吞吐视作在线输入延迟。
5. **泛化与接口仍有空白。** 实验基于英语 BEAT2 的 25 位说话人，跨语言、跨文化与不同动作采集分布尚未验证。方法要求转录文本参与语义预测，又使用学习的 ID 嵌入；未见身份的具体 ID 配置和自动转录流程未交代，公开代码缺席使这些细节暂时无法静态核验。
6. **实验表存在尺度不一致。** 同名 FGD 在不同任务中使用不同显示尺度，部分消融与重建表还存在近十倍差异。阅读时应使用同表对照，不能把这些数值拼成统一排行榜；本文也没有独立复现其统计显著性或运行性能。

## 相关工作与启发

- **[ZeroEGGS](https://github.com/ubisoft/ubisoft-laforge-ZeroEGGS)（Computer Graphics Forum 2023）：** 同样用参考动作控制未见风格，说明示例控制不一定需要自然语言标签。PersonaGest 的区别在于用分层离散表示与语义引导生成来组织内容和风格，而非仅用一个整体风格表示。
- **[SemTalk](https://openaccess.thecvf.com/content/ICCV2025/html/Zhang_SemTalk_Holistic_Co-speech_Motion_Generation_with_Frame-level_Semantic_Emphasis_ICCV_2025_paper.html)（ICCV2025）：** 强调逐帧语义与节奏协调。PersonaGest 将语义进一步引入内容码本分区与重新遮蔽优先级，同时增加参考风格残差生成。
- **[MoMask](https://arxiv.org/abs/2312.00063)：** 为分层动作 token 的掩码生成与残差预测提供直接基础。PersonaGest 加入语音、语义引导和风格参考，并将身体残差层赋予风格监督，而不是直接照搬文本到动作的条件。
- **[MECo](https://arxiv.org/abs/2507.20220)：** 也通过动作示例控制共语动作，但采用语言模型和示例 token 提示；PersonaGest 没有使用自然语言大模型，而是使用内容/风格分层的掩码 Transformer。两者的“动作 token”都不应自动理解为人工编写的可读符号。
- **启发：** 如果希望虚拟人长期保持个人表达习惯，可以把内容、风格和解码约束分别设计并分别评测。对展示型角色而言，这篇论文提供了风格条件的组织方式；要进一步准确指物或保持指定轨迹，仍需要额外的空间控制机制和最终动作校验。
