## 一句话总结

GraphMotion 先把一句动作描述展开成“整句意图—动作动词—方向、对象、方式等属性”的层级语义图，再用三个有先后依赖的扩散模型，分别生成 2、4、8 个连续动作潜变量，最后解码为完整人体动作。它把细节变成可单独建模和调节的条件，改善文本与动作的对应；图上的节点和边仍是神经生成器的软条件，并不是按时执行、精确计数或保持指定姿态的约束程序。

## 研究背景与动机

**领域现状：** 2023 年的文本到动作模型已经能从一句话生成自然的人体运动。MLD 等方法先用 VAE 把动作压缩到低维连续空间，再用扩散模型学习文本到动作潜变量的映射；这种做法降低了直接在逐帧运动空间去噪的成本。

**现有痛点：** 同一句话包含的信息并不等价。“一个人向左走，再用双手拿起东西”既有走和拿两个动作，也有方向、先后关系和用哪只手等属性。模型可能抓住“走、拿”就得到较好的整体匹配，却漏掉“向左、双手”。作者把这种倾向称为学习不均衡，并用遮住动词、只留下属性的实验进行检查。

**核心矛盾：** 一个紧凑的整句表示需要同时承载整体意图、多个动作和细粒度属性；生成器又要从这个表示一次性恢复密集运动。文本中的局部差别容易在压缩和跨模态生成中被弱化。论文提出的是一种结构化建模办法，而不是证明 Transformer 必然无法表达这些信息。

**本文目标：** 让模型更重视动作属性、更好地生成复合动作，同时给用户提供比改写整句文本更直接的细节控制入口，例如加强向左的方向条件或调整某个动作在整段运动中的相对影响。

**切入角度：** 文本本身具有层级：整句话描述全局运动，动词描述局部动作，动词的语义角色描述参与者、方向和方式。先显式拆分这些信息，再让生成过程也采用由粗到细的层级，而不是只在输入端多加一些词。

**核心 idea：** 用语义角色解析构造三类节点和十二类关系，通过关系感知的图注意力交换上下文；同时学习三种容量逐渐增大的动作潜空间。前一级生成的动作潜变量参与后一级去噪，后一级也能读到更多层的文本节点，最终由细节层解码整段运动。[正文 §1、§3](https://proceedings.neurips.cc/paper_files/paper/2023/file/31fc85f7461ce71eadf27fb7281973bd-Paper-Conference.pdf#page=3)

## 方法详解

### 整体框架

可以沿两条路线读这套系统：文本路线负责把语言拆成图，并得到全局、动作、属性三组条件；动作路线先学习三个连续潜空间，再依次生成粗、中、细三种表示。图结构与生成阶段互相对应，但文本中的动作节点没有被逐一绑定到某个动作潜变量或一段固定帧区间。

### 关键设计

#### 1. 先做语义角色解析，把动词与属性分别暴露出来

GraphMotion 使用基于语义角色标注工具的解析器。对每个动词，提取它所关联的短语及其角色，构成三层结构：

| 层级 | 节点表示什么 | 例子与作用 |
| --- | --- | --- |
| Motion | 完整动作描述 | 整句作为一个全局意图节点 |
| Action | 句中的动词 | 走、蹲下、拿起等动作节点，连接到全局节点 |
| Specific | 与动词关联的属性短语 | 向前、双手、某个物体等，通过角色边连接到相应动作 |

关系类型区分“谁执行”“对谁执行”“向哪里”“以什么方式”等，完整类型见下表。像 `ARGM-TMP` 这样的时间角色仍是一段文本的语义标签，没有附带起止帧、持续秒数或执行完成标志。[补充 B.1、表 A](https://proceedings.neurips.cc/paper_files/paper/2023/file/31fc85f7461ce71eadf27fb7281973bd-Supplemental-Conference.pdf#page=2)

| 边类型 | 原表含义 | 理解 |

| ARG0 | agent | 动作执行者 |
| ARG1 | patient | 动作作用对象 |
| ARG2 | instrument, benefactive | 工具或受益者 |
| ARG3 | start point | 起点 |
| ARG4 | end point | 终点 |

| ARGM-MNR | manner (how) | 方式 |
| ARGM-TMP | time (when) | 时间语义 |
| ARGM-DIR | direction (where to/from) | 方向 |
| ARGM-ADV | miscellaneous | 其他修饰 |
| ARGM-MA | motion-action dependencies | 整体运动与动作的依赖 |
| OTHERS | other argument types, e.g., action | 其他关系 |

</details>

这一步解决的是“让模型明确看见哪些词在修饰哪个动作”。它没有引入环境中的真实物体、三维接触点或外部任务状态；例如 `something` 仍只是文本短语，不会自动成为一个具有位置和碰撞体的可操作物体。

#### 2. CLIP 提供节点语义，关系感知 GAT 让节点交换上下文

论文使用冻结的 CLIP ViT-L/14 文本编码器，节点维度为 768。整句取全局汇总表示，动词取对应 token 特征，属性短语对其词特征做均值池化。这里保留了词级信息，而不只是把同一个整句向量复制给每个节点。

仅拆节点还不够：“pick”在不同上下文中含义不同，“with both hands”可以帮助它确定具体动作。因此，GraphMotion 用图注意力聚合相邻节点。其注意力分数由两项相加：一项是所有关系共享的匹配，另一项取决于边的角色类型；随后在邻居上做 softmax，以权重汇总邻居特征，再通过残差连接保留原节点表示。

用简化记法，节点更新可写为：

```text
节点线性投影：h_i = W v_i
边打分：共享匹配项(h_i, h_j) + 关系类型匹配项(h_i, h_j, r_ij)
邻居归一化：a_ij = softmax_j(边打分)
节点更新：V_i = ELU(Σ_j a_ij h_j) + v_i
```

共享部分减少每种稀有关系单独学习完整变换的负担；关系项保留“方向”和“方式”等差异；残差项用于缓解多次聚合使节点趋同的问题。最终得到三组上下文增强表示 `Vᵐ / Vᵃ / Vˢ`。注意力是学习到的相关性，不是逻辑推理的证明链。[正文 §3.1、式 1–3](https://proceedings.neurips.cc/paper_files/paper/2023/file/31fc85f7461ce71eadf27fb7281973bd-Paper-Conference.pdf#page=4)

#### 3. 用三种连续 VAE 表示整段动作，而不是把动作量化成离散词

每个动作 VAE 都用 Transformer 把整段真实动作编码为少量连续潜变量，再通过解码器恢复目标长度的序列。编码器和解码器分别包含 9 层、4 个注意力头；训练目标是重建误差与 KL 正则，KL 权重为 `10⁻⁴`。本文不照抄式 4 中 KL 参数顺序作为实现定义，具体实现另见代码核查。

| 粒度 | 潜变量形状 | 本层希望承担的职责 |
| --- | --- | --- |
| Motion | 2 × 256 | 压缩地表示整段运动的大体结构 |
| Action | 4 × 256 | 增加容量，容纳更丰富的动作组合 |
| Specific | 8 × 256 | 更细致地重建动作属性和运动细节 |

**2、4、8 是压缩容量，不是两次、四次、八次动作，也不是固定的事件数量。** 这些 token 是连续实数向量，没有离散码本或 VQ 查表；它们通过重建学习得到，不是人工标注的“走路 token”“手部 token”。本文也没有用真实的事件区间监督来保证每个潜变量对应一个语义单元。更大容量在重建 FID 上有优势，但附录中的检索和多样性并不全部随容量增大而改善。[正文 §3.2、补充表 D/E](https://proceedings.neurips.cc/paper_files/paper/2023/file/31fc85f7461ce71eadf27fb7281973bd-Paper-Conference.pdf#page=5)

输出沿用动作特征表示，包含根运动、关节位置、速度、旋转以及足部接触特征。把接触状态作为输出的一部分，不等于在生成时强制足底无滑动；本文也没有物理仿真闭环。[附录 E.1](https://proceedings.neurips.cc/paper_files/paper/2023/file/31fc85f7461ce71eadf27fb7281973bd-Paper-Conference.pdf#page=21)

#### 4. 三个扩散模型逐级条件化，后一级重新生成更细的潜变量

三个阶段各自有去噪网络和潜变量：

```text
整体层：噪声 zᵐ → 去噪器 φ_m，条件 Vᵐ → 完成的整体潜变量
动作层：噪声 zᵃ → 去噪器 φ_a，条件 [Vᵐ, Vᵃ, 完成的 zᵐ] → 动作潜变量
细节层：噪声 zˢ → 去噪器 φ_s，条件 [Vᵐ, Vᵃ, Vˢ, 完成的 zᵃ] → 细节潜变量
最终：细节层潜变量 → 对应动作解码器 → 完整长度的运动
```

例如动作层不是拿两枚整体层潜变量“补两个位置”变成四枚，而是在自己的四枚潜变量空间去噪，同时读取前一级结果。细节层同理。因此，论文中的“refine”应理解为有条件的层级生成，而不是对前一段姿态逐帧加一个小修正，也不保证未编辑区域保持原样。

扩散训练冻结预训练 VAE，以三层噪声预测误差之和训练去噪网络。训练时每层噪声日程长度为 1,000；推理使用 DDIM，可以把三个阶段的实际步数限制在合计 50 或 150。它的粗到细发生在整段运动的表示粒度上，没有以时间因果方式逐帧输出的设计。[正文 §3.2、式 5–6](https://proceedings.neurips.cc/paper_files/paper/2023/file/31fc85f7461ce71eadf27fb7281973bd-Paper-Conference.pdf#page=5)

#### 5. CFG 强化条件，图编辑提供相对控制入口

论文采用 classifier-free guidance：训练时以 10% 概率去掉条件，推理时结合有条件与无条件噪声预测，报告的引导强度为 7.5。它提高条件的影响，但引导强度也可能影响生成多样性；这与调整某一条语义边的权重是两种不同层次的操作。[补充 B.2](https://proceedings.neurips.cc/paper_files/paper/2023/file/31fc85f7461ce71eadf27fb7281973bd-Supplemental-Conference.pdf#page=2)

论文展示两类图编辑：一类改动连接权重，例如加强“转向—向左”关系，让示例中的向左运动更明显，或加强整句到某个动作的关系，让它在示例中占据更长的片段；另一类直接替换、屏蔽、增加或删除节点，例如把“walks”替换为“runs”，或加入跌跌撞撞的方式属性。

这些例子说明结构化条件具有可操纵性，但没有给出“边权 2 倍对应位移 2 倍”这样的标定，也没有报告跨样本的时长误差、严格次数成功率或非编辑区域保持率。重新生成时其他运动内容仍可能变化。[正文图 5/6、§4](https://proceedings.neurips.cc/paper_files/paper/2023/file/31fc85f7461ce71eadf27fb7281973bd-Paper-Conference.pdf#page=9)

### 一个完整例子

沿用原文图 1 的意图：“一个人向前走，然后蹲下，用双手拿起某物，再站起并继续走。”下面是帮助理解的信息流，不是本次运行模型得到的结果。

1. **解析文本。** 整句成为 Motion 节点；走、蹲下、拿、站起、继续等形成 Action 节点；向前、然后、某物、双手等形成相应的 Specific 节点。共享短语可能与多个动作发生关联，不能把所有属性简单排成互不相干的词表。
2. **图中交互。** “双手”向“拿”传递方式/工具相关上下文；“某物”补足动作作用对象；全局节点汇总整句结构。具体关系分类由解析器产生，不能把示意图当成对任意同义句都固定不变的解析结果。
3. **整体层生成。** 用全局图表示从随机噪声生成两个潜变量，表达整段动作的粗结构。这里并没有先输出一张可读的动作清单。
4. **动作层和细节层生成。** 后两层依次加入动作、属性条件和上一层完成的潜变量，生成四枚、八枚连续潜变量。最终解码器一次恢复目标长度的动作序列。
5. **调节与验收。** 用户可以改变属性节点或相应边权后重新生成。若应用要求确实双手接触物体、在指定时刻拿起、保持走路段不变，则还需要针对最终动作的检测、场景约束或编辑机制；这不是 GraphMotion 已经完成的部分。

### 训练与推理设置

| 项目 | 论文报告设置 |
| --- | --- |
| 文本编码器 | 冻结 CLIP ViT-L/14，节点维度 768 |
| 动作潜变量 | 三层 token 数 2 / 4 / 8，维度均 256 |
| VAE | 编码器和解码器各 9 层、4 头，重建 + KL |
| 优化 | AdamW，学习率 `10⁻⁴`，4 张 Tesla V100，总 batch 512 |
| HumanML3D | VAE 6,000 epochs；扩散阶段 3,000 epochs |
| KIT | VAE 30,000 epochs；扩散阶段 15,000 epochs |
| 训练噪声日程 | 每层 1,000 步；β 从 `8.5×10⁻⁴` 到 `0.012` |
| 推理采样 | DDIM；50 步示例为 15 + 15 + 20，150 步为 50 + 50 + 50 |
| 条件引导 | 条件丢弃 10%，CFG scale 7.5 |
| 作者报告的训练时间 | VAE 16 小时、去噪器 24 小时，4 张 V100；不自行推算为每个子模型的耗时 |

这些是论文的实验设置，公开仓库里的默认配置未必与它完全相同。相同总采样步数只控制了部分成本，不能自动推出相同显存、模型参数量或端到端时延。[正文 §4、补充 B.3](https://proceedings.neurips.cc/paper_files/paper/2023/file/31fc85f7461ce71eadf27fb7281973bd-Paper-Conference.pdf#page=7)

## 亮点与洞察

- **把“细节被忽略”转成可检查的结构设计。** 属性不再只隐含在一个整句向量里，而是有独立节点、关系和进入生成器的路径。语义图单独就改善了消融中的 FID，说明增益并非全来自多跑几次扩散。
- **语言层级与动作容量一起变化。** 更细阶段既读到更多文本条件，也有更多动作潜变量，最后还能依赖粗阶段结果。这是一个联合设计；它没有单独证明“语义层级”是每一项提升的唯一来源，后续比较还应控制参数量和表示容量。
- **遮蔽动词是有针对性的压力测试。** 它检查模型是否能从方向、方式等剩余词恢复合理运动，比只报告普通测试集更贴合动机。但它仍是特定分布的文本扰动测试，不足以证明所有动作属性都被完整执行。
- **控制入口有可解释性，输出仍需验收。** 改一条边能说清楚用户想加强哪种关系；至于最终多走了多少米、某动作延长几秒、其他动作是否改变，则需要另一个运动层评测。这种“条件可解释”和“结果可测量”的区分，对于设计动作控制系统很有用。
- **附录揭示了实用取舍。** KIT 的 50 步 FID 好于 150 步，HumanML3D 的 300 步 FID 好于 150 步但检索下降，1,000 步又没有继续稳定改善。选择配置应以目标指标和实际耗时为依据，而非默认越细、越久越好。

## 局限与展望

- **解析误差会进入生成条件。** 动词漏检、短语归属错误和复杂句法都可能改变语义图。正文没有提供独立的图解析准确率、错误类型统计或解析噪声鲁棒性实验，不能把图构造看成天然正确的监督。
- **时间关系主要隐式学习。** 三层是语义粒度，不是时间轴；它没有显式事件起止、先后执行器和次数计数器。“先 A 后 B”或“做三次”的成功率需要对最终动作单独评估。
- **随机生成和 VAE 重建带来能力上限。** 作者承认扩散随机性可能产生不理想结果，动作 VAE 也限制了可恢复的细节。图结构无法补回已被动作表示丢掉的信息。
- **不是严格的源动作局部编辑。** 论文的主要接口由文字或语义图生成动作，没有把任意输入动作的非编辑帧或关节硬复制到结果中的机制。改节点后重采样，与保留源动作只改一个部分，是不同的任务。
- **没有物理与场景保证。** 表示里有足部接触特征，语义里可以有物体名称，但生成仍不保证脚不滑、手能触达、身体不穿透或人与物体同步受力。
- **效率结论受测试口径约束。** 附录提供平均每样本时间，但不构成流式首帧延迟或包含新文本解析成本的完整测量；部分设置比 MLD 更慢。多个去噪器还需要各自权重，不能仅按采样步数估计部署成本。
- **公开代码不等于已完成复现。** 上文代码事实来自固定版本的静态阅读，本次没有运行模型、训练或复现论文指标。资源缺口与实现差异会影响能否直接使用论文所示控制流程。

## 相关工作与启发

- **[MLD（CVPR2023）](https://arxiv.org/abs/2212.04048)：** 是连续动作 VAE 加潜空间扩散的重要基础。GraphMotion 在这一框架上加入结构化语言图、三种动作潜变量容量和逐级条件化；它没有改成离散 token 自回归模型。
- **[层级图视频—文本检索（CVPR2020）](https://openaccess.thecvf.com/content_CVPR_2020/html/Chen_Fine-Grained_Video-Text_Retrieval_With_Hierarchical_Graph_Reasoning_CVPR_2020_paper.html)：** 是论文明确引用的图语义建模来源，体现了从整句、动作到实体/属性的结构化表示思路。GraphMotion 将相关结构用于生成条件，任务和输出与检索不同。
- **[CoMo（ECCV2024）](/blog/eccv2024-como/)：** 同样强调可解释控制，但控制表示走向可读的姿态码及其编辑。GraphMotion 操作语言侧语义图，不能直接等同于已经固定某个身体部位的姿态。
- **[Event-T2M（ICLR2026）](/blog/iclr2026-event-t2m/)：** 后续工作用事件子句组织复杂文本条件；GraphMotion 更早地通过语义角色关系表达层级结构。二者都值得分别检查“条件分得清楚”和“输出事件真的按要求完成”。
- **[MSCoT（arXiv2026）](/blog/arxiv2026-mscot/)：** 也采用粗到细思路，但使用多尺度离散表示和解码后目标梯度，而 GraphMotion 使用连续 VAE 潜空间与语义图条件。不能因二者都分层，就把 MSCoT 的几何目标优化能力归给 GraphMotion。
- **对可控动作系统的启发：** 可以把语义图作为用户意图的编辑界面，再设计独立的输出验证：动作是否遗漏、先后是否正确、次数是否精确、指定手是否完成目标、非编辑部分是否漂移。若验证失败，再用显式约束或反馈纠正；后半部分是本文提出的应用方向，不是原论文已经实现的闭环。
