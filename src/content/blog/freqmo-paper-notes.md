## 一句话总结

FreqMo 先在**编码后的动作潜序列**上做多层小波分解，再用一个共享码本由粗到细编码残差，让缓慢变化的整体运动与短促变化的细节拥有不同的时间粒度；最后用一个文本条件掩码 Transformer 联合生成各尺度 token。它主要改进的是动作的表示方式：在更少 token 下保留较好的快速变化，同时用连续扩散分支检验这套表示是否能迁移到另一类生成器。[摘要、Method、表1–2][paper]

## 研究背景与动机

**领域现状：** 很多文本到动作方法先把连续运动编码成固定时间间隔的潜变量或 token，再让自回归、掩码预测或扩散模型生成这些表示。MoMask 一类残差量化方法可以逐层补回重建细节，但每层通常仍使用相同的时间网格；表示层并没有明确规定哪一层负责慢变化、哪一层负责短促变化。[Introduction、Related Work][paper]

**现有痛点：** “一个人向前走，突然绊了一下”同时包含持续的步行趋势和短时间的急剧加速度。如果每个 token 都覆盖同样长的时间窗口，较慢的部分可能使用了冗余表示，绊倒瞬间的细节却可能被平均掉。论文图5用步行绊倒、跳水等例子说明：只看姿态序列的大轮廓，有时不容易发现模型漏掉了局部加速度峰值。[图1、图5][paper]

**核心矛盾：** 人体运动的变化速度并不均匀，表示却常用单一时间分辨率。把窗口统一缩短会增加序列长度；把窗口统一拉长又容易损失瞬态信息。仅给同一 token 增加速度或加速度特征，也没有从结构上把不同时间尺度拆开。[Introduction][paper]

**本文目标：** 建立一种兼顾慢变化与快变化、保留事件发生位置、并能供生成模型使用的紧凑表示；不仅提高动作分布指标，还检查速度高阶变化和高频重建是否得到改善。[Introduction、Experiment][paper]

**切入角度：** 小波变换用较大的时间支撑分析慢变化、较小的时间支撑分析快变化，兼顾频率和时间定位。这里的“尺度自适应”主要来自固定的小波层级及不同长度的频率表示，并不是模型先检测“落脚、挥手”等语义事件，再为每个事件自适应切分 token。[Method，式1–3][paper]

**核心 idea：** 将动作潜变量拆为多尺度结构，再按“先重建粗结构 → 对剩余误差重新分解 → 编码更细尺度”的顺序，统一量化到同一个码本。生成器同时看见所有尺度，通过时间位置、尺度标签和注意力偏置协调它们，再把各尺度贡献还原到同一潜序列长度并相加，解码为完整运动。[图2–3、算法1–2][paper]

## 方法详解

### 整体框架

主方法分成**表示学习**和**条件生成学习**两步。第一步训练动作编码器、共享码本和解码器，得到可重建运动的多尺度离散编码；第二步冻结 tokenizer，训练文本条件掩码生成器预测这些编码。推理时，从全掩码序列出发迭代补全各尺度 token，再复用共享码本及动作解码器输出运动。FreqMo-Diff 是另外验证的连续版本，不是主方法推理时必经的第三阶段。[Method、Implementation details][paper]

### 关键设计

1. **潜空间小波分解：同时保留频率尺度和时间位置。**

   动作编码器 E<sub>M</sub> 先把 T 帧运动 X 压缩成潜序列 h，实验的时间压缩倍数为4。随后沿潜序列的时间轴使用离散小波变换 DWT：一对互补滤波器将输入分为低频近似 A 和高频细节 D，并减少时间采样点；继续分解 A，就得到更粗的近似和多个细节层。[Method，式1–3][paper]

   <div class="equation">h = E<sub>M</sub>(X)<br/>(A<sub>l</sub>, D<sub>l</sub>) = DWT(X<sub>l</sub>)，X<sub>1</sub> = h，X<sub>l+1</sub> = A<sub>l</sub><br/>h = IDWT<sup>L</sup>(A<sub>L</sub>, {D<sub>l</sub>})　（未量化时）</div>

   较粗尺度的一个位置对应更长时间范围，较细尺度的位置更密。这使“整段在缓慢向前移动”和“某处突然抖动”的变化不必完全挤在相同粒度内。实验采用5层 Daubechies-2（db2）小波。精确重建性质约束的是 DWT 与 IDWT 这对变换；它不能追回动作编码器已经丢失的信息，也不能消除后续码本量化误差。

2. **统一频率残差量化：每次编码当前残差，而非独立量化固定细节带。**

   一个容易误读的地方是：算法并不是先算出固定的 A<sub>L</sub>、D<sub>L</sub>……D<sub>1</sub>，然后给每个频带独立查一次码本。算法1从残差 R=h 开始，先量化最粗低频近似；把量化向量通过 IDWT 恢复到完整潜序列长度，细节输入设为0，再从 R 中减掉这部分贡献。随后对**更新后的残差**重新做较浅的小波分解，提取新的低频近似，继续量化。最后直接量化剩下的完整长度残差 R，得到 z<sub>0</sub>。[算法1][paper]

   <div class="equation">R ← h；从 l = L 到 1：<br/>A<sub>l</sub> ← 当前 R 的 l 层小波低频近似<br/>z<sub>l</sub> = Quantize(A<sub>l</sub>, C)<br/>S<sub>l</sub> = IDWT<sup>l</sup>(Lookup(z<sub>l</sub>, C), 0)<br/>R ← R − S<sub>l</sub><br/>最后：z<sub>0</sub> = Quantize(R, C)</div>

   这是算法1的紧凑改写。每一步都使用**同一个共享码本 C**，规模为512个、每个512维向量。粗层先承担较慢的结构，细层逐步补偿剩余误差；这些细层因此兼有更细运动变化和前面量化误差的修正，不宜理解为完全纯净、互不重叠的语义类别。

   表3展示的一个配置共有 **4、5、8、14、26、49** 个 token，合计106；它们分别对应从粗到细的六组 z<sub>5</sub>……z<sub>0</sub>。注意：算法下标由5降到0，而表3将同一粗细顺序标为 L0（Base）到 L5（Fine），两套编号方向不同。

3. **共享解码：恢复各层贡献后相加，而不是拼接关节或动作片段。**

   解码时，对各组 token 从同一个 C 中取出向量。z<sub>5</sub> 到 z<sub>1</sub> 分别经过对应深度的 IDWT，把细节支路置零并恢复到原潜变量长度；z<sub>0</sub> 已经处于该长度，直接作为最终残差相加。最后只需一个动作解码器 D<sub>M</sub>。[算法2、图3][paper]

   <div class="equation">ĥ = ∑<sub>l=1…L</sub> IDWT<sup>l</sup>(Lookup(z<sub>l</sub>, C), 0) + Lookup(z<sub>0</sub>, C)<br/>X̂ = D<sub>M</sub>(ĥ)</div>

   相加的是潜特征向量，各层都对整段运动产生贡献；不是把“走路 token”和“绊倒 token”按事件顺序串成几个独立动作，也不是把身体部位分开解码。

4. **一个掩码 Transformer 联合预测所有尺度。**

   共享码本让各尺度 token 使用同一词表。作者将 z<sub>L</sub>……z<sub>0</sub> 排成一个序列，训练时随机遮住一部分位置，通过全序列自注意力和对 CLIP 文字特征的交叉注意力恢复被遮住的 token。生成器不需要先用一个模型生成基础层，再换另一个模型生成残差层。[Text-to-Motion Generation Model，式5][paper]

   为了让不同密度的 token 对齐，一个 token 使用其所在层内的归一化位置 τ=(k+0.5)/N<sub>l</sub> 做正弦位置编码，另加可学习的尺度嵌入。两层在同一时刻附近的 token 因而可以建立联系，同时保留各自的尺度身份。这里对齐的是时间坐标，不是人工标注的落脚时刻或动作边界。

5. **尺度感知注意力：防止数量更多的细层 token 掩盖粗结构。**

   细尺度有更多 token，若不加区分，注意力可能主要受这些位置影响。论文为较粗层设置较大的权重 w<sub>l</sub>，其原始形式为 log(T<sub>max</sub>/T<sub>l</sub>)，再跨尺度归一化；把两个位置的尺度权重和加入注意力 logits：[式4][paper]

   <div class="equation">M<sub>bias</sub>[i,j] = w<sub>l(i)</sub> + w<sub>l(j)</sub><br/>Attention(Q,K,V) = softmax(QKᵀ / √d<sub>k</sub> + M<sub>bias</sub>)V</div>

   直觉是让网络在补充细节时继续参考较粗的结构，而不是让密集细层主导全部信息交互。按标准逐行 softmax 理解，固定查询 i 的 w<sub>l(i)</sub> 会在归一化时抵消，起到相对偏置作用的是不同键位置 j 的尺度权重；这是对原公式的数学解释。去掉这项设计后 FID 从0.040变为0.053，说明它在论文配置下有帮助，但不是对语义动作或接触的硬约束。

6. **连续变体：检查小波表示是否依赖离散量化。**

   作者另做 FreqMo-Diff：保留小波表示，使用 VAE 和扩散解码路线替代 UFRQ 的离散方案，报告它相对 MLD 的改进。该结果支持“这种多尺度表示可以用于连续模型”，但主文对这一变体的网络、损失和采样配置披露较少，不能据此把全部收益精确归因于某一个分解操作。[Generation Performance、表1][paper]

### 一个完整例子

沿用论文图5的“**一个人走路时绊了一下**”。下面是解释数据流的教学例子，具体 token 内容和中间曲线没有进行实际运行。

1. **表示学习时**，真实运动先被编码成 h。最粗组以少量位置概括长时间尺度的变化；系统重建这部分后，从 h 中减去它，再对剩余变化逐层编码。绊倒附近的短促变化可以通过更密的残差层保留。
2. **条件学习时**，原动作的六组 token 是目标，文字经 CLIP 提供语义条件。模型看到被遮挡的部分 token，学习利用文字和其他尺度的已知位置补全它们。
3. **生成时**，不再需要真实动作。按待生成的序列长度准备所有尺度的掩码位置，模型在12轮内预测、按置信度保留部分 token，并继续补全其余位置。各尺度在同一轮联合预测，而非粗层完成后才开始训练另一个细层模型。
4. **解码时**，各组 token 查码、逆小波还原并相加，得到完整潜序列，再生成运动。图5展示了作者样例中较接近真实序列的加速度峰值；它没有证明用户可以指定“第1.3秒必须绊倒”，也没有证明某个频带就是可单独操纵的“绊倒”符号。

### 训练/推理

**训练数据：** HumanML3D 包含14,616条运动、44,970条描述；KIT-ML 包含3,911条运动、6,278条描述。论文报告使用镜像增强，并按0.8∶0.05∶0.15划分训练、验证、测试。[Experiment / Setup][paper]

**第一步训练 tokenizer：** 编码器和解码器采用残差块，时间下采样4倍，5层db2小波，共享码本512×512。目标是动作 L1 重建损失，加上各层量化前特征与停止梯度码本向量之间的 commitment 项，权重 β=0.25。训练200,000次迭代，batch size 512，学习率2×10<sup>−4</sup>。[Training Objective、Implementation details][paper]

**第二步训练生成器：** 冻结 tokenizer，以原动作编码为监督。掩码 Transformer 有8层、6个注意力头、隐藏维度384，掩码比例ρ=0.3；仅对被遮住的位置计算交叉熵。训练100,000次迭代，batch size 64。[式5、Implementation details][paper]

**推理：** 从全掩码开始，执行12次置信度驱动的补全，得到六组离散码后一次完成表示重建与动作解码。因此文中的“single-stage generation”指一套生成器联合处理各尺度，不等于一次前向即可输出全部运动。论文报告使用单张 NVIDIA 4090，但未给出足以核算完整训练成本的训练时长或 GPU-hours。[Inference、Implementation details][paper]

| L4 | 0.1–1.5 Hz | 26 | 0.11 | 0.19 |
| L5：最细残差层 | 0.1–2.5 Hz | 49 | 0.04 | 0.12 |
| 完整表示 | 0.0–2.5 Hz | 106 | 0.04 | 0.04 |

这些范围存在重叠，应按原表的层级统计阅读，不应画成互不重叠的理想频带分界。基础层单独拿出来并不足以生成高质量完整运动，但在完整系统中移除它破坏最大。[表3][paper]

### 消融实验

**Tokenizer设计，原表4 Group 1：** 分别改变多尺度、小波分解和残差量化的组合，结果如下。

| 配置 | 多尺度 | 小波 | 残差量化 | FID ↓ |
|---|:---:|:---:|:---:|---:|
| 单尺度 | 否 | 否 | 否 | 0.141 |
| 误差残差扩展 | 否 | 否 | 是 | 0.082 |
| 时间域多尺度 | 是 | 否 | 是 | 0.064 |
| 频域、无残差量化 | 是 | 是 | 否 | 0.092 |
| 完整 FreqMo | 是 | 是 | 是 | **0.040** |

**生成器组件：** 去掉尺度感知注意力，FID由0.040升至0.053；改用自回归生成，FID为0.088。[表4 Group 2][paper]

**分解深度：** L=1、2、3、4、5、6时，FID分别为0.087、0.075、0.052、0.059、0.040、0.043。5层最佳，但从3层到4层出现回退，不能概括为随层数单调改善。[表4 Group 3][paper]

**小波基选择：** Haar/db1、db2、db4、Symlet-3的FID分别为0.059、0.040、0.065、0.042。论文默认db2；Symlet-3接近，但db4明显更差，不能据此说小波基的选择没有影响。[表4 Group 4][paper]

### 关键发现

1. **更好的动作分布不等于每项文字对齐指标都更好。** HumanML3D上FID由MoMask的0.045变为0.040，但FreqMo的Top-1、Top-3与MM Dist.均未超过该基线。KIT-ML上文本对齐较好，但含检索增强的ReMoDiffuse仍有更低FID。[表1][paper]
2. **重建收益主要体现在动态细节，位置误差存在取舍。** 相对RQ-VAE₆，Accel下降约10.8%、Jerk下降约9.2%、HF-RMSE减半；MPJPE则从28.7变为29.5。106对294意味着token约减少64%，或原方法约为它的2.77倍，论文“约三倍压缩”的表述不应扩展成三倍推理加速。[表2；比例按原数值计算][paper]
3. **粗层与细层具有互补作用。** 表3累计加层的FID从6.44降到0.04；单独移除最粗层最伤整体结构，移除任一细层也降低质量。该证据支持层级互补，不意味着每层独立对应一种动作语义。[表3][paper]
4. **小波与残差 refinement 的组合优于仅保留其中一项。** 频域但不做残差量化为0.092，时间域多尺度残差为0.064，完整配置为0.040。连续分支也比表中的MLD更好，但尚不足以排除具体网络与训练设置对增益的影响。[表1、表4][paper]
5. **效率证据要看测量口径。** 图8报告FreqMo的平均推理时间AIT为0.12秒，MoMask为0.18秒；T2M为0.04秒，因此FreqMo并非图中绝对最快的方法。文中没有完整说明统一的序列长度、批大小和计时条件，这些作者报告的数值不能直接转成已复现的交互系统性能承诺。[图8][paper]

## 亮点与洞察

- **把表示的时间粒度作为设计对象：** 与只增大生成器不同，FreqMo首先改变模型需要生成什么。慢变化使用较少位置，快速变化使用较密位置，给出一个可与生成模型分开研究的表示方向。
- **把可逆分解与有损编码分开：** 小波本身提供明确的分析／重建操作，UFRQ承担压缩。这样能够分别检查频率层级、残差误差和token预算，而不是把所有变化都归到一个不透明的潜空间。
- **联合生成减少多尺度之间的级联：** 所有尺度可以在同一Transformer中相互参照，尺度与时间嵌入提供对应关系；这与必须依次运行多个生成模型的设计不同。
- **直接查看加速度、jerk与频谱：** FID之外的证据帮助识别短促变化被抹平的问题。尤其是重建表暴露了“位置精度略差、动态变化更好”的取舍，比只报告一个总分更有信息量。[表2、图5–7][paper]

## 局限与展望

- **潜频率与物理运动频率需要区分。** 小波作用于学习后的、4倍下采样的潜序列，表3的最高范围为2.5Hz；图6却展示解码后运动到6Hz的功率谱。完整网络能够在输出中重建较高频率，但“潜变量小波可逆”不能独自解释输出全部高频信息的来源。进一步分开测量编码器、量化器和解码器的贡献，会使机制归因更清楚。这是依据处理链与图表提出的阅读判断。
- **频率层级不提供现成的动作事件语法。** 本文没有让用户输入逐关节约束、指定某一帧的足底接触，或给某层绑定“行走／挥手”等语义名称；也没有报告跨动作交换频带后能稳定保留内容或风格的控制实验。若用于可编辑动画，还需要额外控制接口与解码后约束验证。
- **连续变体和复现细节仍不充分。** 已取得的9页v1给出主要离散算法与训练配置，但未完整展开FreqMo-Diff的结构、HF-RMSE定义、频带估计口径、计时协议及小波边界处理。文中提到附录和补充视频，当前PDF未包含这些内容，公开入口也尚未核实。[全文][paper]
- **实验范围集中在标准文本到动作数据集。** 当前证据不足以推到手指细节、语音驱动手势、多人物交互、长期流式生成或物理控制；更好的加速度曲线也不自动等于更准确的接触、更少穿模或动力学可执行。
- **还需要更严格的相同预算比较。** 106与294 token的对比体现了压缩收益，同时也改变了生成问题的规模。若以相同码长、相同网络容量、相同训练计算量比较不同表示，会更清楚地分离频率组织和预算配置的收益。这是后续实验建议，而非论文已经完成的结论。

## 相关工作与启发

- **[MoMask](https://ericguo5513.github.io/momask/)（CVPR 2024）：** 同样使用残差量化与掩码建模，但其基础层掩码Transformer和残差Transformer分工生成多层编码；FreqMo把尺度引入表示本身，并由一套掩码生成器联合预测所有尺度。两者不能简单等同为“残差层数不同”。
- **[MLD](https://chenxin.tech/mld/)（CVPR 2023）：** 先学习VAE动作潜空间，再在潜空间做扩散。FreqMo-Diff借此检验小波表示能否迁移到连续生成，但现有主文对该分支的披露比离散分支少。
- **[DiffusionPhase](https://arxiv.org/abs/2312.04036)：** 也利用频率相关的紧凑表示，但采用参数化周期信号建模运动，并用扩散预测其参数；FreqMo使用保留局部时间位置的小波层级和离散残差码。周期／相位参数与局部小波尺度是不同的组织方式，不应把两者都概括为同一种“相位token”。
- **启发：** 对可控动作系统，可以先研究“哪些信息适合低频整体条件，哪些适合局部细节条件”，再设计生成与编辑接口。FreqMo提供了一个有结构的表示起点；若要把它升级为事件级或身体部位级控制，仍需独立验证条件如何影响最终解码运动，而不能直接将频带当作语义标签。
