## 一句话总结

这篇论文让扩散模型同时接受“要做什么”的文本和“怎样做”的参考动作，并用文本注意力寻找两段动作中语义相近的时刻，再注入相应风格。它无需风格标签来训练适配器，但仍依赖文本—动作配对数据；内容保持通过注意力与软损失实现，并不保证源动作的每一帧、轨迹或接触被精确保留。

## 研究背景与动机

**领域现状：** 文本到动作模型擅长表达“走路、坐下、再站起”这样的动作内容。要描述弓背、迟疑的步态或拳击手在不同动作中的习惯姿势，单靠一句风格形容词往往不够。因此，SMooDi 等方法让用户额外提供一段参考动作，以动作本身传达风格；另一条路线则先生成动作，再调用风格迁移模型进行修改。

**现有痛点：** 假设文本要求“先出拳，再下蹲闪避，最后站起后退”，参考动作来自一位职业拳击手。理想结果既要保留拳击手出拳时的发力方式，也要在闪避和后退时保持防守姿态。把整段参考压成一个不随时间变化的风格向量，容易只留下“抬着双手”的粗略特征；直接搬用参考动作，又可能把文本要求的动作顺序改掉。

**核心矛盾：** 内容与风格共同体现为身体姿态、速度和时序，二者没有天然分开的通道。同一项“弯腰”特征可能是老人风格，也可能是动作内容中必须完成的一次弯腰。风格参考与目标文本的动作内容还可能不同，因此，参考中最明显的特征不一定适合注入目标的每个时刻。

**本文目标：** 在不要求训练集提供风格类别标签的条件下，把参考动作中的细节融入文本指定的动作，同时减少风格迁移对动作内容的破坏。这里的“无监督”限定在风格学习上：模型仍然用 HumanML3D 的文本—动作配对学习生成，并非完全无文本、无监督信号的动作学习。

**切入角度：** 作者没有直接学习“生成动作帧应该对应参考动作的哪一帧”，而是让两者分别关联同一段内容文本。若生成动作的一段和参考动作的一段都关注“坐下”，它们就更适合交换局部风格；“person”这类描述主体的词，还可能支持跨动作共享整体姿态特征。

**核心 idea：** 先训练一个具有动作—文本注意力的扩散模型，再冻结它，学习多时间尺度的风格编码器和 SASI 风格注入分支。SASI 复用已经学到的文本对应关系，选择参考中的相关风格；训练时再用部分自参考重建和髋部速度一致损失，减少模型直接照搬参考的倾向。[原文 §1、§3，PDF 第 2–5 页](https://discovery.ucl.ac.uk/10214396/1/Siggraph_2025__Linjun_Wu_.pdf#page=2)

## 方法详解

### 整体框架

训练分两阶段：先在文本—动作对上训练 Conv1D U-Net 扩散生成器，再固定这个基础模型，训练读取参考动作的风格适配器。常规推理输入内容文本、参考动作和随机噪声；参考动作经过 CNN 形成与 U-Net 各层时间尺度对应的风格特征，SASI 在每层用文本关联生成特征与参考特征，逐步生成风格化动作。模型中的 motion latent 指 U-Net 的中间特征，不能据此把它理解成 VQ 码本或另一个动作 VAE。

### 关键设计

1. **先学习文本控制：为后续风格对齐建立共同坐标**

   基础生成器从带噪动作 x<sub>t</sub>、扩散时间 t 和文本特征 c<sub>t</sub> 预测干净动作。U-Net 的每层让动作特征作为 query、文本 token 作为 key/value，得到动作时刻与文本词语之间的注意力 A<sub>x</sub>。注意力加权的文本 value 被加回动作特征，帮助网络决定每一段该做什么。

   这里重要的不只是得到一个能生成动作的模型，还要得到已经学习过的投影 W<sup>Q</sup>、W<sup>K</sup>。后续风格分支将复用它们，而不是从头寻找参考动作和目标动作的对应关系。基础训练使用预测动作与真实动作之间的均方误差，原文式（11）。

   附录进一步说明：文本端使用 CLIP tokenizer 和四个 Transformer Encoder 块，得到最多 77 个、每个 512 维的文本 token 特征，并掩去零 token。U-Net 共九层：四个下采样层、一个中间层、四个上采样层，同时间尺度间有跳跃连接；扩散时间与文本注意力特征注入残差块。[附录 §2.1](https://dl.acm.org/doi/suppl/10.1145/3721238.3730641/suppl_file/Appendix.pdf#page=1)

2. **风格金字塔：保留随动作变化的局部风格**

   CNN 先在原时间尺度编码参考动作，再通过下采样得到多层风格特征 c<sub>s</sub><sup>i</sup>，分别对应 U-Net 的不同时间尺度。作者举的例子是：老人持续弓背是一种较全局的特征，蹒跚脚步则涉及局部的时空变化。把这些特征全部池化成一个固定向量，会失去“在什么动作阶段采用哪种表现”的信息。

   因此，适配器保留的是一组仍有时间维度的参考特征，而不是一个人工定义的风格类别。它并没有显式输出“弓背强度”“步频”这类可直接解释的控制参数，也不要求用户为参考动作填写风格标签。

   附录给出五层 CNN 风格编码器，每层包含 ResNet1D 块与下采样卷积，产生五种时间尺度的风格特征。训练时以 30% 概率丢弃风格潜特征，促使模型利用不同尺度的信息；这是训练正则，不是用户在推理时选择某种风格的硬开关。[附录 §2.1](https://dl.acm.org/doi/suppl/10.1145/3721238.3730641/suppl_file/Appendix.pdf#page=1)

3. **SASI：用两次文本关联构造动作—参考对应关系**

   对某一层，生成动作特征 x 和参考风格特征 c<sub>s</sub> 分别通过同一组冻结的 query/key 投影，与内容文本建立关联。省略层号和多头细节后，原文式（1）、（4）、（6）、（8）可写为：

   <div class="equation">A<sub>x</sub> = softmax(Q<sub>x</sub>K<sub>t</sub><sup>T</sup> / √d)，A<sub>s</sub> = softmax(Q<sub>s</sub>K<sub>t</sub><sup>T</sup> / √d)<br>B = row-normalize(A<sub>x</sub>A<sub>s</sub><sup>T</sup>)</div>

   A<sub>x</sub> 的每一行描述“当前生成时刻关注哪些文本词”，A<sub>s</sub> 的每一行描述“参考时刻关注哪些文本词”。两行内积越大，说明它们在文本维度上的关注更接近；再按参考时间维度归一化，就得到当前生成时刻应从各参考时刻读取多少风格。

   例如，生成中的坐下片段会更关注参考中的坐下片段，而不必直接复制参考整段动作。作者图 3 还显示，站起与坐下虽然速度方向不同，因姿态相近也可能存在中等注意力。因此，这是一种学习得到的软对应，不是动作阶段的人工标签或严格一一匹配。

   原文式（7）把内积进一步写成余弦相似度，但该等式通常还需要 L2 归一化。当前代码实际执行的是两张 softmax 矩阵的内积和行归一化；本文按上述实际运算解释，不把它当成已实现的标准余弦相似度。[原文式（6）–（8）](https://discovery.ucl.ac.uk/10214396/1/Siggraph_2025__Linjun_Wu_.pdf#page=4) · [SASI 实现](https://github.com/fivezerojun/Semantically-Consistent-Text-to-Motion-with-Unsupervised-Styles/blob/a6e249f68b453625874c9cc140c35c9fc9cb18bd/src/models/architectures/text2stylized_motion.py#L221-L264)

4. **残差式风格注入：保留基础语义路径，学习额外风格贡献**

   将 B 与参考特征的 value 投影相乘，得到 x<sub>style</sub>，然后与原动作特征和文本注意力输出相加。原文式（9）–（10）的核心关系是：

   <div class="equation">x<sub>style</sub> = B V<sub>s</sub>，x<sub>out</sub> = x + x<sub>text</sub> + x<sub>style</sub></div>

   训练适配器时，基础扩散模型及其 Q/K 投影冻结，风格编码器和新增风格分支学习如何调整生成特征。论文将 SASI 中需要训练的投影概括为 W<sup>V</sup>；公开实现还包含可训练的归一化层和零初始化输出卷积，因此“只训练 W<sup>V</sup>”不应被扩大成整套实现的全部可训练参数说明。

5. **自参考裁剪与内容损失：限制直接复制参考的捷径**

   没有风格标签，也没有“同内容、不同风格”的成对真值时，作者让目标动作本身充当风格参考，训练模型恢复该目标。但若给完整参考，网络可能绕过文本，直接从参考取回所有动作细节。论文因此随机截取目标长度的 50%–75% 作参考，让重建还需要依赖文本和生成先验。

   另一条训练路径换成随机抽取的参考动作，并比较有风格分支与基础文本生成分支的髋部速度序列。两者使用相同的带噪动作、扩散时间和文本；内容损失鼓励风格化结果保留基础生成器的运动节奏。总损失为重建损失加 0.5 倍内容损失，原文式（12）–（14）。这不是用真实源动作逐帧监督所有关节，也不能推出接触时刻或空间轨迹被硬性锁定。[原文 §3.3](https://discovery.ucl.ac.uk/10214396/1/Siggraph_2025__Linjun_Wu_.pdf#page=5)

6. **分开调节文本与风格引导：把取舍留到采样时控制**

   附录采用多条件 classifier-free guidance。以 p∅ 表示无条件预测、p<sub>t</sub> 表示只有文本的预测、p<sub>ts</sub> 表示文本与参考风格共同条件的预测，式（3）可简写为：

   <div class="equation">p̂ = p∅ + λ<sub>t</sub>(p<sub>t</sub> − p∅) + λ<sub>s</sub>(p<sub>ts</sub> − p<sub>t</sub>)</div>

   默认 λ<sub>t</sub>=2.5、λ<sub>s</sub>=1.5。风格项是“在已有文本条件上再加入风格”的增量，因此两种条件可分别调节；训练时文本和风格条件各有 10% 的丢弃概率，以学习相应预测分支。增大 λ<sub>s</sub> 确实能加强风格分类分数，但附录的对照也显示语义、FID 与脚滑会变差，它不是无代价的风格强度旋钮。[附录 §2.3、§3.4](https://dl.acm.org/doi/suppl/10.1145/3721238.3730641/suppl_file/Appendix.pdf#page=2)

### 一个完整例子

沿用原文图 4(a)：文本要求“一个男人连续刺拳，下蹲闪避，然后站起并后退逃开”，参考是一段职业拳击手动作。

首先，文本编码器保留描述动作和顺序的 token 表示，风格编码器从参考中提取出拳、屈膝、防守姿态等时变特征；这里列举的特征名称是便于理解的解释，并非模型实际输出的人工标签。生成从随机噪声开始，基础扩散路径逐步形成刺拳、下蹲、起身和后退的动作内容。

在每个去噪步的相应 U-Net 层，SASI 比较当前生成时刻和参考时刻对文本的关注：刺拳阶段更适合读取参考中的出拳风格，闪避和后退阶段则读取较相符的姿态特征。风格 value 通过加权和加入动作特征，而不是把参考某一帧直接写入最终骨架。

作者展示的结果在出拳时保留拳击动作的特点，并在下蹲、起身和后退时保留防守姿态。这个案例说明参考中的风格可以随动作阶段变化；它没有提供逐关节误差或时间对齐真值，因此不能据图宣称每一步动作边界或参考细节均被精确复现。[原文图 4(a)，PDF 第 7 页](https://discovery.ucl.ac.uk/10214396/1/Siggraph_2025__Linjun_Wu_.pdf#page=7)

### 训练/推理

**训练。** 两阶段均使用 HumanML3D 的训练划分。第一阶段学习文本条件生成器；第二阶段冻结基础生成器，学习风格 CNN 与 SASI 新增分支。附录披露使用单张 NVIDIA RTX 4090、batch size 64，基础模型训练 200k 次迭代、适配器训练 80k 次迭代。两阶段初始学习率分别为 1×10⁻⁴ 和 5×10⁻⁶，采用 Adam、weight decay 0.01；每 5,000 步学习率下降 5%，梯度范数裁剪上限为 1。扩散训练为 1,000 步，β 从 0.0001 线性增加至 0.02。迭代次数不能换算成论文没有报告的训练小时数或项目总计算量。[附录 §2.2](https://dl.acm.org/doi/suppl/10.1145/3721238.3730641/suppl_file/Appendix.pdf#page=1)

风格标签不参与基础适配器训练；SRA 评估则使用人工风格标注，附录明确说在测试数据的一个子集上训练分类器，但没有完整交代该分类器训练子集与参考评估子集的独立划分。100STYLE 上另有使用监督分类器引导的推理变体，要与基础方案分开。

**常规推理。** 输入内容文本、参考动作和目标长度，由噪声开始多步去噪。当前公开配置采用 DDIM 50 步；50 步来自代码，附录没有明确给出相同的推理步数。文本与风格 CFG 的默认权重 2.5 和 1.5 则同时得到附录与代码确认。额外的 `--use_guidance` 指使用风格分类器的引导，与不依赖分类器的 CFG 是两回事。[公开推理配置](https://github.com/fivezerojun/Semantically-Consistent-Text-to-Motion-with-Unsupervised-Styles/blob/a6e249f68b453625874c9cc140c35c9fc9cb18bd/configs/modules_stage2_stylization/scheduler.yaml) · [风格配置](https://github.com/fivezerojun/Semantically-Consistent-Text-to-Motion-with-Unsupervised-Styles/blob/a6e249f68b453625874c9cc140c35c9fc9cb18bd/configs/config_stage2_stylization.yaml)

**扩展应用。** 对已有动作做风格迁移时，论文先通过 DDIM inversion 得到源动作对应的噪声，再结合内容文本和另一段风格参考重新生成。对关键帧补间，论文结合 imputation／inpainting 与参考风格，展示沿用关键帧风格或在不同风格间过渡。这两项主要由图 5–6 定性展示，主文没有给出关键帧误差、未编辑区域保持误差或完整编辑基准，不能据此升级为具有精确保留保证的通用动作编辑器。[原文 §6，图 5–6](https://discovery.ucl.ac.uk/10214396/1/Siggraph_2025__Linjun_Wu_.pdf#page=8)

**开销与公开实现。** 主文与附录披露了上述硬件和训练迭代数，但没有训练墙钟时长或推理耗时，不能据此声称实时生成。官方仓库提供两阶段 `train.py`、评测 `test.py`、生成及 BVH 导出 `visualize.py`。但在本次固定版本中，主要 demo 没有提供上述源动作 inversion 或关键帧补间的完整调用入口，仅存在逆调度器声明不能证明这些应用已经可直接复现。

### 消融实验

**SASI、内容损失与风格金字塔，原表 3。** 其余设置不变，分别替换文本中介、移除内容损失，或仅使用三层 CNN 最后一层特征。[原表 3、§5.3](https://discovery.ucl.ac.uk/10214396/1/Siggraph_2025__Linjun_Wu_.pdf#page=7)

| 设置 | R@3 ↑ | MM Dist ↓ | SRA ↑ | FID ↓ |
|---|---:|---:|---:|---:|
| 完整方法 | 0.715±0.002 | 3.496±0.011 | 65.739±0.247 | 1.186±0.011 |
| w/o SASI | 0.520±0.003 | 4.905±0.010 | 74.906±0.289 | 5.117±0.042 |
| w/o content loss | 0.643±0.003 | 3.953±0.013 | 68.667±0.241 | 1.837±0.020 |
| w/o pyramid | 0.719±0.003 | 3.483±0.011 | 60.813±0.383 | 1.135±0.014 |

**文本中介：** 用普通交叉注意力直接让生成动作 query 读取参考 key/value，替换 SASI。R@3 从 0.715 降到 0.520，FID 从 1.186 升到 5.117，但 SRA 从 65.739 升到 74.906。直接注入更容易强化分类器可识别的风格，同时破坏内容与动作分布。

**内容损失：** 去除髋部速度一致约束后，R@3 降到 0.643，FID 升到 1.837，SRA 却升到 68.667。该约束的作用是优先保护内容，并非同时提高所有风格指标。

**多时间尺度：** 把风格金字塔换成三层 CNN 的最终输出，SRA 从 65.739 降到 60.813；但 R@3、MM Dist 和 FID 的均值略好。金字塔主要改善风格表现，不能概括为全面提升语义与生成质量。

**移除 SMooDi 的分类器引导：** SRA 从 52.040 降至 31.953，说明分类器对风格识别贡献很大；与此同时，其 R@3 升至 0.694、FID 降至 0.416，后者优于本文默认设置的 1.186。这条补充结果限制了“本文生成质量全面最好”的说法。

### 关键发现

1. **主要收益是兼顾内容与风格。** HumanML3D 表 1 中，本文方法的检索、MM Dist、FID 和脚滑指标优于所列生成基线，但 SRA 低于 DecouplingContact 组合。人工评分三项最高，为另一种评价视角提供了支持，仍不等于所有动作和风格都成功。
2. **监督分类器会显著改变跨域结果。** 100STYLE 的 SRA 从基础适配器的 34.962 增至有分类器引导的 76.112。后者证明的是组合系统的效果，不能只归功于无风格标签学习，也不能直接与 HumanML3D 的 SRA 横比。
3. **内容保持和风格强度确实存在取舍。** 移除 SASI、移除内容损失、调高风格 CFG 都出现“语义变差、SRA 变好”。MoMo 也得到更高 SRA，而 SMooDi 无分类器设置得到更低 FID。应同时检查内容、风格和质量，不能把单项最高当作整体最好。

## 亮点与洞察

- **把文本作为对应关系的中介：** 文本不仅是生成条件，还为两段没有帧级配对的动作建立软联系。这个思路比直接比较姿态特征更容易利用已训练模型中的语义知识。
- **风格可以随动作阶段变化：** 时变风格金字塔避免只用一个全局标签概括整段参考，为“拳击时的发力”和“后退时的防守”分别提供信息。它也提醒我们，风格不一定是可独立于动作内容的一组固定属性。
- **冻结生成先验，学习新增分支：** 先保留已有文本控制能力，再学习风格残差，降低适配器完全改写生成机制的需求。本文的注意力和内容损失共同约束这一适配过程。
- **消融揭示评价目标之间的冲突：** SRA 很高不一定意味着风格化结果更可用。对动作编辑系统，语义符合、风格接近、源细节保持和物理合理性需要分别检查。

## 局限与展望

1. **内容与风格冲突时，风格可能被压制。** 原文图 7 的文本是跳绳，参考为双臂前伸的僵尸动作。模型保留了摇绳所需的手臂运动，因此没能充分表现参考的前伸双臂。如何让用户指定哪项风格可牺牲、哪项内容必须保留，仍是后续方向。
2. **语义对应不等于精确编辑约束。** 注意力是软权重，髋部速度损失也只是训练正则。源动作迁移和补间没有提供系统的未编辑区域保持、关键帧误差或接触误差评测，不能承诺只修改某个关节或某个时间段。
3. **无风格标签不意味着风格已经完全解耦。** 自参考训练仍包含目标的内容信息，裁剪与内容损失只能减轻捷径。跨域 SRA 和消融中的明显取舍表明，风格参考与目标动作不匹配时仍可能损失风格或语义。
4. **评测覆盖有限。** HumanML3D 的 SRA 来自测试数据中人工标注子集训练的分类器，但完整类别与训练／评估子集的独立划分未交代清楚。16 人的人评虽包含 4 位专业动画设计师并说明了评分标准，仍是有限规模研究，没有报告置信区间或显著性检验。
5. **距离直接复现还有发布缺口。** 代码已公开，但当前模型下载地址失效，扩展编辑入口与完整训练成本也未核实。若要接入动画流程，还需实际验证动作数据处理、权重、骨架转换与生成结果，而不能只依据仓库存在就判断可直接部署。

## 相关工作与启发

- **[SMooDi（ECCV2024）](https://neu-vi.github.io/SMooDi/)：** 同样以内容文本和参考动作为输入，使用风格适配与风格引导。本文的主要变化是让文本参与生成动作与参考风格的时间对应，并以不需要风格标签的方式训练基础适配器；它也另外测试了带监督分类器引导的设置。
- **[StableMoFusion](https://h-y1heng.github.io/StableMoFusion-page/)：** 提供文本到动作的扩散生成框架。本文基于 Conv1D U-Net 和交叉注意力建立基础文本生成器；实验还将 StableMoFusion 与后接的风格迁移模型组合，比较直接风格生成与两阶段处理。
- **[MCM-LDM（CVPR2024）](https://xingliangjin.github.io/MCM-LDM-Web/)：** 从内容、轨迹和风格多条件出发做动作风格迁移。本文默认任务从文本和参考直接生成动作，扩展迁移则使用 DDIM inversion 与文本语义先验；两者不能因为都使用参考动作就视为完全相同的控制接口。
- **[MoMo（SIGGRAPH Asia2024）](https://monkeyseedocg.github.io/)：** 在推理时操作预训练动作扩散模型的自注意力，将 leader 的动作轮廓与 follower 的表现特征结合，无需为该迁移流程重新训练模型。本文则先训练风格适配器，用文本建立语义对应；附录比较的输入条件不同，且 MoMo 的 SRA 更高，应保留这项取舍。
- **[DecouplingContact](http://www.cad.zju.edu.cn/home/jin/SigA20241/Decoupling_Contact.htm)：** 本文受到髋部运动与接触时序关系的启发，用髋部速度约束减少内容漂移。实验同时表明，更强的风格表达可能伴随语义指标下降，因而接触、内容和风格需要分开评价。
- **启发：** 对需要“照着参考表现，但仍完成指定动作”的角色系统，可以借鉴文本中介与软内容约束；若业务要求精确指向、固定轨迹或局部不变，还要另行设计显式约束和最终动作验证，不能把注意力对齐当作这些保证。
