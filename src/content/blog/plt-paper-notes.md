## 一句话总结

PLT 把物理角色的全身动作先验拆成躯干和四肢各自的离散技能，再用一个全身协调网络修正它们；任务策略只需选择各部位的技能编号，就能驱动低层控制器完成跟踪、导航等任务，并通过局部训练扩展特定身体部位的能力。

<span id="reading-2" class="reading-anchor"></span>

## 研究背景与动机

**领域现状：** 物理角色动画通常先让角色模仿动捕，学到走、跑、跳等动作先验，再训练一个高层策略调用这些先验完成任务。PULSE 用连续潜变量，NCP 用离散潜变量：高层负责“用什么技能”，低层负责把技能落实为关节控制，物理仿真计算角色接下来如何运动。

**现有痛点：** 全身只有一个潜变量时，手臂动作、躯干姿态和步态容易绑在一起。想让腿执行新学到的蹲伏或侧移，同时保留已有上身瞄准能力，往往需要重新学习整个人的动作分布。稀疏跟踪或关节受损时，高层也难以灵活重组不同部位的能力。

**核心矛盾：** 分开表示有利于组合与局部更新，但身体在物理上是耦合的。手臂发力会影响平衡，腿和躯干需要共同维持重心；简单把几个局部技能拼起来，会产生不协调甚至不稳定的全身行为。

**本文目标：** 同时得到可组合、可局部适配的动作先验和可靠的物理控制，在维持动作自然度的前提下改善全身模仿、少量身体部位跟踪及目标导航。

**切入角度：** 作者从先验的组织方式入手：把一个全身码本改成多个部位码本，让潜变量按控制关节划分；再显式学习一个读取全身状态和全部部位 token 的小幅修正网络，补回部位之间的协调信息。

**核心 idea：** 先通过专家蒸馏学会“各部位技能 + 全身协调”，再冻结这套低层能力，训练任务策略选技能。需要新风格时，仅更新对应部位的码本、控制器及部分协调参数，而不是重新学习全部低层策略。

## 方法详解

### 整体框架

PLT 的输出是物理仿真中的动作控制，不是一段可以直接播放的离线关节动画。预训练阶段使用当前角色状态和未来参考动作学习部位先验；下游阶段改由任务目标驱动高层策略选 token；两条路径共用部位码本、协调网络与低层控制器。另有一条可选的局部适配训练路径，用来更新指定部位的能力。[正文 §3–5、图 3](https://dl.acm.org/doi/pdf/10.1145/3721238.3730637#page=4)

### 关键设计

1. **分部位 token：把“整个人做什么”分解成可组合的局部技能。**

   模仿阶段，一个编码器接收当前全身状态 s 和参考动作，输出连续潜向量 y。把 y 按身体部位拆成 y₁…yₖ，每一段在自己的码本 Bₖ 中找最近的向量。原式 (3) 可写为：

   **zₖ = argmin<sub>e∈Bₖ</sub> ‖yₖ − e‖²。**

   k 是身体部位，e 是该部位的可学习码字。PLT-1 使用整个身体；PLT-2 分上身与下身；PLT-5 分躯干、左右臂与左右腿。实验在不同划分之间控制码本参数总量，按部位自由度分配潜变量维度，因此不能把提升简单归因于“给五个部位各复制了一份完整模型”。

   token 是学习到的控制潜变量，既不是“抬手”这样的可读标签，也不是固定关键帧。每个低层部位策略还要读取**当前全身状态**，才能决定该部位应输出哪些 PD 关节目标；相同 token 在不同身体状态下不必产生完全相同的关节轨迹。

2. **Refinement：用一个全身残差修正局部组合。**

   仅靠独立码本容易让动作局部合理、整体不稳。协调网络 R 同时看到 s 和全部部位 token，输出一个同维度的修正量，再按部位分回去：

   **Δz = R(s, z₁, …, zₖ)，ẑₖ = zₖ + Δzₖ。**

   每个部位的低层策略使用 ẑₖ 而不是原始 zₖ。原式 (5) 另加 **L<sub>refine</sub> = ‖Δz‖²**，约束网络只做必要调整，避免所有动作信息都绕过离散码本走连续通道。可把它理解为“腿和手各自提出技能，协调层根据整个人的状态微调”，而非完全独立的五个控制器。

   最后，各部位输出合并成关节位置目标，由 PD 控制器和仿真器产生实际运动。这一步很重要：网络输出的目标与角色在重力、接触和惯性作用下实际达到的姿态不是同一个量。

3. **专家蒸馏：先学会模仿，再学离散结构。**

   直接让含量化层和多个部位的策略从零用强化学习学会所有动作，训练会比较困难。作者先训练没有这种潜变量正则限制的专家，再训练 PLT 学生。学生在仿真里产生自己的状态分布，专家在这些状态上给出目标动作，学生最小化与专家的动作差异。

   原式 (6)–(7) 为：**L<sub>action</sub> = ‖a − a<sub>expert</sub>‖²**；**L = L<sub>action</sub> + αL<sub>reg</sub> + βL<sub>commit</sub> + γL<sub>refine</sub>**。其中 L<sub>reg</sub> 保持潜变量的时间平滑，L<sub>commit</sub> 让连续编码与量化表示匹配，L<sub>refine</sub> 限制修正幅度。

   这里的 online distillation 指**训练时由学生在线收集状态**，并不意味着部署时需要专家持续陪跑，也不意味着角色在用户使用过程中自动更新权重。

4. **RVQ 与任务策略：预训练精细重建，任务阶段只选第一层技能。**

   模仿阶段采用残差向量量化，每个部位有 8 层、每层 1,024 个码字。后层编码前层还没表示好的残差，以改善模仿质量。

   到下游任务，高层是一个以 s 和任务目标 g 为输入的 PPO 策略，输出 K 个离散编号；每个编号只索引相应部位的**第一层 RVQ 码本**。作者认为第一层集中了大部分动作信息。这个设计降低了高层搜索难度，因此不能把它描述成“高层在 K×8 个码本上自由生成完整精细动作编码”。

   此时冻结码本、全部低层策略和 refinement，只训练高层任务策略。它是共享输入的多离散动作策略，而不是 K 个各自独立训练的强化学习智能体。与 NCP 相比，作者也省去了额外的 prior shifting 阶段。[正文 §3–5](https://dl.acm.org/doi/pdf/10.1145/3721238.3730637#page=3)

5. **局部适配：按部位增加能力，同时保留其他参数。**

   适配时冻结编码器和非目标部位的先验，更新目标部位的码本与低层策略；论文还解冻 refinement 的第一层来稳定协调。由于混合动作数据很难获得一个现成专家，适配阶段直接使用 PPO，而不是再训练专家进行蒸馏。

   例如，先让腿学会 Assassin 数据里的蹲伏和侧移，保留已有上身能力；随后只让躯干和手臂学习 Handball。部位结构使“更新哪部分能力”变成明确的参数选择。

   但冻结未选部位的权重，**不等于未选部位的最终运动逐帧不变**。低层还读取全身状态，refinement 涉及多个部位，物理仿真也会传播运动影响。这是先验的局部适配，不能直接当成源动作编辑中的硬保持约束。

### 一个完整例子

沿用论文图 7 的能力扩展案例，可以把过程理解为：

1. 先从 LaFAN1 学到 PLT 的全身模仿先验，随后以 LaFAN1 的瞄准动作作为组合与保持评测的一部分。
2. 构建上身瞄准、下身 Assassin 风格的混合参考目标。在 PLT-5 中更新双腿码本和双腿低层策略，并进行有限的协调网络适配。
3. 仿真每一步把全身状态与参考目标交给冻结的编码器，得到部位潜变量；码本和 refinement 处理后，各低层策略给出 PD 目标，角色在物理环境中尝试跟随混合动作。
4. 再把上身目标换成 BML Handball，只更新躯干和双臂对应的先验，腿继续调用此前学到的 Assassin 能力。
5. 最后分别测试新组合、前一阶段组合和原始动作，以检查新增能力是否以严重遗忘为代价。

这是**需要进一步训练的适配流程**。论文没有证明只输入一段文本指令，就能在运行时零训练地让任意身体部位学会任意风格；图 7 也显示保留的是一定程度的旧能力，而非旧行为完全不变。[正文 §6.3、图 7](https://dl.acm.org/doi/pdf/10.1145/3721238.3730637#page=9)

### 训练 / 推理

| 阶段 | 输入 / 监督 | 更新内容 | 输出及使用方式 |
| --- | --- | --- | --- |
| 专家训练 | 当前状态、参考动作；动作模仿与风格奖励 | 专家策略 | 可在学生访问的状态上给出目标控制动作 |
| 模仿蒸馏 | 学生访问的状态、参考目标、专家动作 | 编码器、RVQ、部位低层、refinement | 具备离散部位先验的物理模仿策略 |
| 下游任务训练 | 当前状态、任务目标、任务奖励 | 高层多离散 PPO 策略 | 为每个部位选择首层码字；其余先验冻结 |
| 下游运行 | 当前状态与目标 | 无梯度更新 | 选 token → 全身修正 → PD 目标 → 仿真 → 新状态 |
| 可选局部适配 | 新旧部位组合参考及模仿奖励 | 目标部位先验及部分 refinement | 更新局部技能；不是常规推理必经步骤 |

LaFAN1 设置使用 28 自由度 humanoid、2.9 小时动作；AMASS 设置使用 69 自由度 SMPL humanoid 和筛选后的 40 小时动作。Assassin 含 46 段约 5 分钟的商业动捕，用于分布外评测与适配。所有参考动作需重定向到相应物理角色。高层和低层控制都为 **30 Hz**；这不是包含传感器、渲染、通信在内的端到端延迟测量。

附录披露：LaFAN1 蒸馏使用 8,192 个并行环境、batch 65,536、学习率 2×10⁻⁴、α/β/γ 为 0.005/0.1/0.01；AMASS 对应 3,072 个环境、batch 16,384、学习率 5×10⁻⁴。论文所说 RTX 3090 上“几小时”仅指**部位适配**，未披露覆盖专家、蒸馏、全部任务、消融与失败实验的总 GPU 小时。[正文 §5、§6.3；附录表 9–14](https://dl.acm.org/doi/pdf/10.1145/3721238.3730637#page=5)

MPJPE 为根对齐后的平均关节位置误差，G-MPJPE 为全局坐标下的误差；VelE / AccelE 分别是根速度、根加速度误差，均越低越好。Return 是任务奖励的归一化回报，Success 为成功比例。下表保留原论文数值；原表未在列名标注几何量的单位，故不擅自补写 mm 或 cm。

LaFAN1 模仿评测使用 8,192 条、每条 4 秒的轨迹；其模型也在未参与训练的 AMASS 和 Assassin 动作上跟踪测试。这里“分布外”仍然**提供参考动作**，不是无条件生成未知动作。LaFAN1 对照是在统一环境中重新实现的 PULSE / NCP；AMASS 对照使用 PULSE 的原有环境。不同角色与环境下的表格不应直接混算排名。[正文 §5–6.1、表 1–2](https://dl.acm.org/doi/pdf/10.1145/3721238.3730637#page=6)

5 点跟踪时，PLT-5 的位置误差与回报优于两项基线。只跟头部时，NoR 却以更差的全身误差取得更高回报：奖励只关注被观测部位，未观测身体仍可能出现较差姿态。**任务回报与全身动作质量不能互相替代。** N 不同也对应不同奖励约束，不能用 Return 大小判断“1 点跟踪一定比 5 点更容易实现用户目标”。

### 5. 消融：分别改了什么，结果如何

**去掉协调网络。** 主表 1–3 已包含全部 NoR 数值：它在 Assassin 模仿、5 点跟踪和受损导航上明显退步，但在部分 AMASS 误差及 1/3 点任务回报上不差甚至更好。结果支持“协调对某些困难组合重要”，并不支持无条件优越。

## 亮点与洞察

- **真正改变的是控制先验的组织方式。** 部位拆分同时作用于码本、高层动作空间和低层输出关节，因此能够明确选择更新对象；它不只是对网络加一个注意力模块。
- **独立表达与全身协调被分开建模。** 码本提供局部可组合性，refinement 用带惩罚的小残差处理物理耦合。这种分工比假定各肢体可以完全独立更符合角色动力学。
- **重建最优与控制最优可以分离。** 八层 RVQ 服务于模仿重建，首层码字服务于高层任务搜索；512/1,024 的消融也说明，不能只依据重建误差决定可用的技能空间。
- **局部扩展比从头重练更适合持续增加角色能力。** 实验检验了新组合和旧任务，提供了比只展示一段成功动画更实在的保持证据；但保持程度仍有限，需要用旧任务回归评测持续检查。
- **奖励可能掩盖动作问题。** 1 点跟踪 NoR 的最高回报与较差全身误差并存，提醒我们同时检查接触、平衡、未观测关节和视觉自然度。

## 局限与展望

### 论文自身的范围

作者明确指出，身体划分是人工设计的；最合适的分组可能随任务变化。各部位独立码本也会重复学习类似技能，例如左右臂各存一份近似动作，存在参数冗余。共享码本与自动划分是作者提出的方向。

实验证据来自指定 humanoid、重定向动作与 Isaac Gym 环境。没有证明任意骨架拓扑都能直接使用，也没有提供自然语言输入、手指精细交互、嘴型或眼神控制的完整方案。局部适配展示的不是对任意源片段的逐帧保留。

稀疏跟踪实验具有约 0.17 秒前视，并使用从动捕构造的信号；真实设备的延迟、丢帧、噪声、标定和身体比例变化需要额外验证。损伤实验则是在训练中纳入损伤分布，不能外推到所有未见的结构破坏。

### 公开实现与复现边界

[官方仓库](https://github.com/jinseokbae/plt/tree/fa0bef2d47776b6b5169e34df9490b754211fccf)提供 Isaac Gym Preview 4 环境下的训练和测试说明，列出了专家、PLT-5 模仿、1/3/5 点跟踪、普通与受损导航等预训练模型的使用命令，并提供 [Google Drive 权重入口](https://drive.google.com/file/d/1LL7ryKVfo1cOdsLXA6uSQvxNk_NClS_t/view)。本次确认代码和下载入口存在，没有验证权重压缩包的内容、完整性或可加载性。

数据也不是一键齐备：仓库给出 LaFAN1 重定向工具，完整重定向数据需自行准备；AMASS 依赖其原始获取流程，Assassin 涉及商业动作数据。仓库代码的许可、NVIDIA 组件的许可与动作数据的许可应分别检查。

还有一处值得复现者留意的差异：**论文称局部适配解冻 refinement 第一层；当前公开 Assassin 适配配置默认的 `fine-tune` 分支选择输出线性层，`fine-tune-3` 才选择第一层。** 这是静态检查发现的论文/配置差异，不能据此直接断言作者实验用了哪个分支，也不能未经运行就判定其性能影响。[配置文件](https://github.com/jinseokbae/plt/blob/fa0bef2d47776b6b5169e34df9490b754211fccf/isaacgymenvs/cfg/train/MotionTransfer/LafanAssassinPLTAdaptationPPO.yaml) · [参数选择实现](https://github.com/jinseokbae/plt/blob/fa0bef2d47776b6b5169e34df9490b754211fccf/isaacgymenvs/learning/cvae_agent.py)

### 对交互角色的可用启发

若把它用在一个需要站立、移动、做手势的虚拟角色上，可以考虑由上层行为规划产生任务目标，再由分部位技能和物理控制器执行。但这只是系统设计启发；仍需补齐目标接口、动作库覆盖、角色重定向和实时性能验证。游戏或 Unity 场景中的碰撞、物体状态、交互规则和网络同步也需要实际系统管理，不能由离散 token 自动保证。

## 相关工作与启发

- **PULSE：连续的全身动作先验。** PLT 与它同属先学动作能力、再训练任务控制的路线，但把全身连续潜变量改成部位离散技能。PULSE 在密集奖励 VR 跟踪中仍然更强，说明表示选择应与监督密度及任务结合，而非只看总体优胜数量。相关定义与统一对照见[正文 §2、§5–6](https://dl.acm.org/doi/pdf/10.1145/3721238.3730637#page=2)。
- **NCP：离散技能控制的直接参照。** PLT 延续量化动作先验，却把单个全身 token 换成多个部位 token，并增加全身 refinement；下游是多离散动作空间。论文实现还给 NCP 与 PLT 都使用 RVQ，因此比较并不只是“RVQ 对普通 VQ”。
- **Part-wise Motion Priors（PMP）：按身体部位学习先验的前序思路。** PLT 的区别在于把部位技能显式组织为码本和低层控制策略，提供可选取的离散动作接口及局部参数更新路径；“分部位”一词本身并不能保证两类方法具有相同控制方式。[正文相关工作](https://dl.acm.org/doi/pdf/10.1145/3721238.3730637#page=2)
- **AnyTop：拓扑泛化与部位控制解决不同问题。** [AnyTop](https://anytop2025.github.io/Anytop-page/)面向不同骨架拓扑的动画生成；PLT 在固定物理角色上讨论技能组合与任务适配。前者能处理多种骨架，不代表输出已经通过物理执行验证；后者有物理反馈，也不代表可以零训练换任意骨架。
- **AutoKeyframe：稀疏关键帧与离散技能不是同一种 token。** [AutoKeyframe](https://github.com/Cr7st/AutoKeyframe)先生成动作关键帧再补间，PLT 的编号则选择状态相关的控制潜变量。若两者结合，需要从目标动画到可执行控制的接口及跟踪评测，不能把关键帧编号直接塞进 PLT 码本。
