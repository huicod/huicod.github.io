# 博客分类维护

分类是阅读导航，不替代论文原有标签，也不表示代码已复现或约束必然满足。

## 数据与入口

- `src/data/paper-facets.json` 以文章文件名（不含扩展名，即 Astro 的 slug）为键。
- `src/data/paper-taxonomy.ts` 定义主题、方法和控制类别的 ID 与显示名称。
- 新增解读时补充分类；正文、发布时间、标题和既有标签不因分类改写。
- 未分类的新文章暂归“其他研究与笔记”，不会从默认列表或搜索中消失。
- 草稿可以预先归类，但列表、搜索及分类计数都排除草稿。

## 归类原则

主题通常选 1–3 个；确实统一多个主要任务的模型可以更多。同一文章在结果中只显示一次。

| 维度 | 归类依据 |
| --- | --- |
| 研究主题 | 文章实际研究的任务和主要贡献。通用动作生成包含文本条件和无文本生成；语音手势、舞蹈、编辑、理解等分别保留入口。 |
| 方法线索 | 对主要机制有意义的方法，不把所有用到 VAE 的文章都归“动作表示”，也不把普通正余弦位置编码归“相位与频域”。 |
| 控制与应用 | 明确的输入或应用能力。内部关键帧选择不等于用户关键帧控制，身体部位网络不等于部位编辑，推理快不等于流式生成。 |

“统一多模态”用于真正共享的多模态或生成/理解框架；普通语音加转录条件不自动纳入。像素视频与骨骼动作必须区分；情绪识别、心超、通用序列算法及工程笔记放在“其他研究与笔记”。

## 浏览行为

不选择条件时保留发布时间倒序及原静态分页，每页 10 篇。

筛选维度之间取交集；有关键词时沿用标题、标签、摘要的原搜索权重，无关键词时沿用原时间顺序。数字表示在其他筛选及当前关键词下可找到的文章数，因此交叉归类的主题计数不能相加。

地址参数为 `q`、`topic`、`method`、`control` 和结果页 `page`。刷新、收藏、分享和从文章返回可恢复选择；筛选变更沿用原搜索的 `replaceState` 行为，不与 Astro 的页面历史路由同时维护一套筛选历史。

修改后检查默认排序、搜索评分、类别交集、两种分页、URL 恢复、空结果、索引加载失败，以及窄屏布局。索引增加字段时验证数据结构，避免旧缓存被误报为零结果。
