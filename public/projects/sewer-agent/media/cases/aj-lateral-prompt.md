**观察重点**　侧壁伸出一段支管，能辨认支管口、外缘与主通道各自的方向。注意规则接入口与异常突入的可见差异。 此处给出构图意图，实际检测输出以运行后保存的任务为准。

## 首轮检查

在工作台点击「新建对话」→「新建检查」，上传此文件，使用「YOLO＋VLM 复检」。使用配置好的文字与视觉服务；核对原始框、复检意见和人工复核状态。 把下面一段填入「检查要求」，点击「提交检查」，再在「任务与证据」中点击「启动检查」。

```text
请检查模拟侧壁接入处，分辨侧向开口、接口边缘及主管通道，保存这次五类检查的候选框和依据。
```

## 追问已保存的证据

同一对话中，先记录首轮任务 ID 和实际候选数。在「附件与检查选项」中关联该任务，不重传素材，再发送下一轮指令。

```text
请解释已保存证据能否支持支管异常接入。接口是否可见、哪些信息需人工确认，请分别说明。
```

在「检查依据」中对照原图、原始框和任务模式，按实际结果记录命中、未检出或待核实。可下载该任务的 JSON 或 HTML 报告。
