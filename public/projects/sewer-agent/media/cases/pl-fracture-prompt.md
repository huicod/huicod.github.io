## 首轮检查

在工作台点击「新建对话」→「新建检查」，上传此文件，使用「纯 YOLO（不复检）」。直接查看原始框、分数与未复检状态。 把下面一段填入「检查要求」，点击「提交检查」，再在「任务与证据」中点击「启动检查」。

```text
请检查这张模拟管道图，保留五类检测器给出的原始框和分数。帮我定位不规则细线与环形接缝；证据不足时保留疑问。
```

## 追问已保存的证据

同一对话中，先记录首轮任务 ID 和实际候选数。在「附件与检查选项」中关联该任务，不重传素材，再发送下一轮指令。

```text
解释这项任务已保存的原始检测。候选框是否覆盖可见细线？若没有候选，请说明检测范围；只使用本次保存的结果。
```

在「检查依据」中对照原图、原始框和任务模式，按实际结果记录命中、未检出或待核实。可下载该任务的 JSON 或 HTML 报告。
