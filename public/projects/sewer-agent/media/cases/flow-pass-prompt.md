# 16 · 接入、堵塞与同框线索短片

[打开模拟短片](flow-pass.mp4)。本片由三张原创模拟图剪辑而成；各镜头轻微缩放，按 3 秒切换，左上标有镜头序号。播放时间只对应本演示片。

**观察重点**　0–<3 秒展示侧壁支管口，3–<6 秒展示管底堆积，6–<9 秒展示右上裂隙及左下堆积同框。 此处给出构图意图，实际检测输出以运行后保存的任务为准。

## 首轮检查

在工作台点击「新建对话」→「新建检查」，上传此文件，使用「YOLO＋VLM 复检」。视频固定使用上述模式。 把下面一段填入「检查要求」，点击「提交检查」，再在「任务与证据」中点击「启动检查」。

```text
请扫描这段带有切镜的模拟视频，按实际保存的时间范围报告侧壁、管底和多线索画面的候选事件。记录每段的检查覆盖程度和可用证据帧。
```

## 选帧与后续工具

在同一对话查看「任务与证据」→「展开视频候选时间线」，记录扫描帧数、覆盖、候选时间与任务状态。等任务达到「已完成」或「部分完成」，在「选择已存证据帧」里点击实际存在的一帧，再发送下一轮指令。没有已存帧时记录该状态；若任务等待人工复核，按实际证据处理。

```text
对选中的一张视频证据帧按需增强。只结合该帧解释可见线索，保留帧号、时间、原图以及增强的选择理由。
```

记录所选帧的时间、视频父任务和工具子任务 ID。区分候选事件、已选证据与已经完成的复检，再打开统一报告对照。
