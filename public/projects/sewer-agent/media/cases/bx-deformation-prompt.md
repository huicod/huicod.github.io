# 10 · BX · 管道变形

[打开模拟图片](bx-deformation.jpg)。图像由 AI 根据文字独立生成，左上标有 SYNTHETIC DEMO。没有现场来源、测量数据或人工缺陷真值。

**观察重点**　前部轮廓局部内凹，较远的轮廓提供形状参照。用相邻截面的差异检查透视和镜头倾斜能否解释所见。 此处给出构图意图，实际检测输出以运行后保存的任务为准。

## 首轮检查

在工作台点击「新建对话」→「新建检查」，上传此文件，使用「纯 YOLO（不复检）」。直接查看原始框、分数与未复检状态。 把下面一段填入「检查要求」，点击「提交检查」，再在「任务与证据」中点击「启动检查」。

```text
请检查模拟管道的轮廓。对照靠近镜头和较远处的截面，记录原始五类候选；只凭当前画面能够说明什么？
```

## 追问已保存的证据

同一对话中，先记录首轮任务 ID 和实际候选数。在「附件与检查选项」中关联该任务，不重传素材，再发送下一轮指令。

```text
根据已保存的结果解释形状异常的位置。区分看得到的内凹、可能的透视效应和还需现场核查的部分。
```

在「检查依据」中对照原图、原始框和任务模式，按实际结果记录命中、未检出或待核实。可下载该任务的 JSON 或 HTML 报告。
