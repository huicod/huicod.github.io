# 15 · 结构线索短片

[打开模拟短片](structure-pass.mp4)。本片由三张原创模拟图剪辑而成；各镜头轻微缩放，按 3 秒切换，左上标有镜头序号。播放时间只对应本演示片。

**观察重点**　0–<3 秒展示破裂场景，3–<6 秒展示变形场景，6–<9 秒展示腐蚀场景。三个镜头来自不同的模拟图片。 此处给出构图意图，实际检测输出以运行后保存的任务为准。

## 首轮检查

在工作台点击「新建对话」→「新建检查」，上传此文件，使用「YOLO＋VLM 复检」。视频固定使用上述模式。 把下面一段填入「检查要求」，点击「提交检查」，再在「任务与证据」中点击「启动检查」。

```text
请按时间扫描这段模拟短片。逐段记录实际候选事件、覆盖时间和已存证据帧；切换镜头时分别核对壁面细线、管道轮廓和表面凹坑。
```

## 选帧与后续工具

在同一对话查看「任务与证据」→「展开视频候选时间线」，记录扫描帧数、覆盖、候选时间与任务状态。等任务达到「已完成」或「部分完成」，在「选择已存证据帧」里点击实际存在的一帧，再发送下一轮指令。没有已存帧时记录该状态；若任务等待人工复核，按实际证据处理。

```text
请按需增强所选的视频证据帧。保留原帧、来源时间以及使用或跳过增强的原因；结论限定于所选画面。
```

记录所选帧的时间、视频父任务和工具子任务 ID。区分候选事件、已选证据与已经完成的复检，再打开统一报告对照。
